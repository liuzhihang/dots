# Dot Studio

A character-first customization and Prompt workspace for Dots, Grok Bot, Muse and animal companions. The catalog contains 57 presets: 9 independently recreated from supplied App screenshots and 48 original extensions. The source links and the distinction between official examples and Studio extensions are visible in the style guide.

## Work locally

```sh
npm ci
npm run build
npm run dev
```

In the managed Sites environment use the supervised `sites-preview` command for browser QA. The static publication directory is `dist`; `src/live` is bundled into `dist/live-runtime.js`. Rebuild the bundle after changing renderer or geometry source.

## State and rendering

- `dist/studio-model.js` owns schema 9, validation, migration from schemas 6–8, constraints and bilingual Prompts.
- `dist/studio-catalog.js` contains the 57 starting configurations and public design sources.
- `dist/studio-layout.css` defines the two-column desktop workspace and the fixed-stage phone layout. The left area contains the character; the single right inspector contains family selection, presets, all settings and Prompt output. Its settings scroll independently, keeping the editable character visible.
- `dist/studio-pickers.js` supplies compact schematic controls for shape, eyes and accessories. Character catalogs, species, hair and action thumbnails are generated by the actual live renderer.
- The Dots appearance panel offers 11 core silhouettes based on the supplied App screenshots and 8 additional Studio shapes. Eight core eye designs have individual geometry, with two extra eye styles in the advanced section. Older saved configurations retain their identifiers.
- The saved state records user intent. `resolveCharacter` derives the effective action, accessories, expression, anatomy and background without erasing that intent. Preview, summary and Prompt consume the effective configuration.
- `src/live/avatar-body.js` creates original volume meshes, facial geometry, layered hair and species-specific anatomy.
- The layered blue character, cloud and frog use smooth continuous volume unions. Human and animal resting limbs are sculpted into compact poses; prop actions replace them as a pair only when contact targets require it.
- `src/live/avatar-props.js` fits accessories and creates exactly one active arm/wing pair with contacts for the selected prop. Head accessories inherit the head transform.
- `src/live/live-preview.js` handles lighting, camera, animation, the main preview and a shared thumbnail renderer. Working and reading views slightly elevate the camera to improve prop-contact readability.
- `src/live/surface-fur.js` attaches short curved fibers to the actual surface. WebGL and software rendering share the same strand geometry and direction.
- `src/live/software-renderer.js` provides a depth-tested Canvas2D fallback for environments without WebGL. It renders the same geometry, materials and fibers; GPU rendering is preferred where available.
- Software materials use filtered bump-map mip levels and smooth-normal shadow bias. Fiber color remains close to its visible parent surface to prevent dirty speckles on light plush regions.
- PNG export uses a separate canvas and an immutable configuration snapshot. Resize, rapid edits and concurrent export clicks cannot overwrite an in-progress export.
- High-resolution art examples remain available in **美术参考**. They are explicitly separate from the editable real-time model.

## Outputs and privacy

The site produces Chinese/English Prompts, TXT files, re-importable JSON and PNGs of the actual preview. A preview PNG is a rendered model frame, not an image-model result. PNG exports honor the chosen aspect ratio and alpha background.

Reference mode stores only text instructions and preservation choices. No reference-image input, upload, image parser or image-generation API is present. **复制并打开 ChatGPT** copies the Prompt and opens ChatGPT; the user pastes it and attaches their image there.

## Verification

```sh
node scripts/verify-studio.mjs
node scripts/verify-atelier.mjs
```

The checks cover intentional state preservation, current versus temporary accessories, species anatomy, Prompt/JSON consistency, and construction of all catalog presets. Browser QA separately verifies visible changes, material quality, real exports and responsive layout.

The workspace is checked against the supplied App references and the requested two-column structure: a large open character stage on the left, family and preset selection inside one right inspector, graphical appearance controls, an action gallery and Prompt output inside that inspector. Phone (390 × 844) and tablet (768 × 844) checks cover horizontal overflow and whether scrolling the settings leaves the character visible. Clipboard and PNG journeys require separate verification through the actual interface. The main stage uses editable geometry, whose fur and hair detail remains below the generated art examples.

## Art direction and scope

The October 2026 refinement follows the supplied character references: full rounded volumes, restrained eyes, softly domed non-round shapes, head-surface accessory fit, complete hair masses, tucked animal paws, combed short fibers and neutral studio lighting. The expanded catalog is original Studio work, not an official asset library. The procedural model is an interactive form/material/action preview; it does not claim to reproduce the full detail of the separately labeled generated art references.

## Screenshot recreations (2026-10-04)

The nine App Characters are separately labeled independent recreations. Their Chinese names are descriptive Studio names; their colors are screenshot-based approximations, not official tokens. Nine approximate App swatches are separate from the original palette. The Pets list in a user screenshot may include custom pets and is not treated as an official catalog.

Schema 9 derives provenance from registered preset identities and visual configuration, preserving original/modified attribution across undo, reset and JSON. Old schema 6–8 files keep their original geometry and colors; no old preset is relabeled as a verified recreation. Eye type, expression and action are independently saved. Sleep temporarily resolves eyes to closed, preserving the chosen expression. Five new distinct expressions are added; tear/sweat accents are optional and off by default.

`editor.html` shares schema 9 and the same session state with the 3D route. It renders a labeled 2D geometric schematic with explicit material/action/camera omissions. Unsupported people and animals keep their full configuration and show an unavailable message rather than a substitute character. Back/Forward cache restoration rehydrates the canonical saved state. The original full schema 1–5 tool and its advanced controls remain at `legacy-editor.html`, independent of the main session state.

Additional checks: `node scripts/verify-recreations.mjs`.

These are Studio originals. **用这套设定开始** loads editable starting parameters from `dist/studio-inspiration.js`. The art PNG remains a fixed material and composition reference; live controls update the procedural character. The editable renderer has lower fiber, hair and fabric fidelity than the generated artwork. Current-preview PNG export captures that renderer, while art-sample export selects the independent source PNG.

- **Agent activity:** Six states are available: idle, thinking, processing, waiting, blocked and done. Thinking and processing offer automatic selection, three matching silhouette forms for blob characters (three small overhead dots for people and animals), flowing tapered droplets, or orbiting particles. `src/live/activity-system.js` implements these Studio interpretations with coordinated character and accessory motion.
- **Random combinations:** Four slots cover type, look, accessories and action, with individual locks and reproducible seeds. Component locks preserve currently visible action props; reference mode keeps the family fixed. Results enter undo history. Escape cancels a pending spin, and editing or undo cancels its delayed commit. Reduced motion removes reel transitions and assembly motion, and starts the live preview paused.
- **Reference workflow:** The site saves preservation choices, text notes and explicit overrides. Users copy the Prompt, open ChatGPT and attach their reference image there. The local preview remains the configured Studio model; Prompt text and JSON carry no reference image.
- **Regression checks:** `verify-atelier.mjs` covers seeded locks, resolved component labels, reference-neck preservation, motion speed, framing and missing motion-field defaults in older v9 files. The build, 57-preset regression suite, 467 recreation assertions and six Atelier cases pass. Browser QA checked 320/390/768 px layouts, random locks and undo, character/prop rendering, and generation of the 1400 px PNG preview. Download-completion events timed out in the cloud browser. The copy action reported success, but the harness clipboard read was empty; download and clipboard delivery are not marked as end-to-end verified.
