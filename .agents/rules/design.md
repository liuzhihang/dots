# 设计实现与验收规则

与 [DESIGN.md](../../DESIGN.md) 配套，最新用户范围及活跃 refocus change 优先于待同步的旧主规范。

1. 保留选定图 1 的中央标题、左右群像、品牌、浅色专题和成品美术身份；UI 使用真实 DOM。无需重画所有角色，不把原型或动漫截图像素转成角色。
2. 专题与标签可扩展；场景群像、示意、候选姿态与发布 Artwork 分开。来源、素材存在、资源验证、艺术批准和目标验证分别记录。
3. 产品没有工作台、自由换装、项目兼容、3D、账户或公共上传。原型里的登录、组装、固定五家族与现场生成文案移除。
4. 图像实际特征与 Prompt 创作意图区分。锁定全部必备特征；随机先冻结有效成品，再逐卡揭晓，预载失败或空池不假完成、不换条件。
5. 一个活动 dialog，详情／随机／参考图内容替换并可返回；保留焦点、滚动、筛选与原结果。关闭取消资源、timer、RAF；迟到回调不更新新会话。
6. 默认透明原图下载原字节，核实 MIME、hash、尺寸、alpha 与画面；UI 底色不进入输出，无脚底阴影团。不支持的动作／动画／目标资源无虚假按钮。
7. 参考图仅描述和条件式模板 Prompt，图片由用户在 ChatGPT 上传；不冒充视觉分析或自动发送。打开时预填 Prompt，失败提供全文与手动链接。随机桌面为一排六张 5:6 卡，手机突出当前卡并露出邻卡；六槽为角色风格、外形五官、配色材质、衣物、配饰、道具。抽取前/进行中不显示硬锁条件面板，结果后可展开 Feature AND 锁定供下一抽；不允许独立重抽或组件穿戴。阶段结果文案为“遇见新的伙伴”；宽屏主图在左、名称/规格/详情在右，六项收拢事实摘要置于其下，然后提供复制/下载主操作；手机主图居中置顶，作品信息之后先放复制/下载主操作，再放六项收拢事实摘要横向轨道，避免 320 px 视口下主操作落得过低。不得滤色或改变 Artwork 原图颜色。复制/下载是结果主操作，再随机/详情/ChatGPT 次级。详情精选标签按语义优先级选择 4–6 个，仅显示值，桌面置于右侧信息栏、手机置于完整大图下方；搜索索引/文件规格分离，主操作前置，移除棋盘格。打开详情或进入画廊／游戏时，初始焦点落在静态 `#overlayTitle`、`#galleryTitle` 或 `#gameTitle`；标题不呈现输入框外观，可交互控件仍须保留清晰的 `focus-visible` 状态。
8. 新制角色与特征材料必须符合身份：Dots 柔软短绒；Grok Bot 软几何和成对胶囊眼，不是屏幕脸；Meta Muse 奶油包覆形体与内嵌脸面。已有批准PNG按具体版本与范围保留；未得到用户材质裁决时不静默改图或扩大批准。
9. 特征卡视觉优先使用有来源的批准高清原图局部；绑定 Asset/版本/hash/sourceRect。不能清楚呈现时使用同等清晰度、语义准确的矢量/文字或登记缺口，不以低质占位、原型截图裁片或工程任务替代用户美术批准。
8. 普通 PNG 不等于 Dot/Pet 安装包。目标资料绑定端／版本／来源／查询时间；无目标实装证据标待验证。首期不制作 Pet 包。
9. 审查实际页面桌面及 320、390、768 CSS px，记录源/cache与资源 hash；模拟视口不等于实体手机，构建或脚本不等于艺术批准。
10. 用户确认具体版本后才能记录新页面艺术批准，不自动接受截图基准；旧记录不可重写，取消任务不改通过。
11. 保留 Site 身份、访问范围、批准美术、来源和历史。旧运行/测试非发布保存；窄范围清理，不能清空 dist。
