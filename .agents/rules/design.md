# 设计实现与验收规则

与 [DESIGN.md](../../DESIGN.md) 配套，遵循最新用户范围与现行主规范；refocus change 已按用户指令带未完成验收归档，具体边界见 [归档交接](../../openspec/changes/archive/2026-10-07-refocus-studio-on-gallery-and-card-reveal/archive-closeout.md)。归档不授予美术批准。

1. 保留选定图 1 的中央标题、左右群像、品牌、浅色专题和成品美术身份；UI 使用真实 DOM。无需重画所有角色，不把原型或动漫截图像素转成角色。
2. 专题与标签可扩展；场景群像、示意、候选姿态与发布 Artwork 分开。来源、素材存在、资源验证、艺术批准和目标验证分别记录。
3. 产品没有工作台、任意自由换装、通用组件适配、项目兼容、3D、账户或公共上传。有限的颜色、形状、五官、衣物或配饰变化可作为已设计成品存在；每个有效搭配必须登记为完整 Artwork，不因多个 Feature 标签而自动生成交叉组合。原型里的登录、组装入口、固定五家族与现场生成文案移除。
4. 图像实际特征与 Prompt 创作意图区分。普通筛选同维 OR／跨维 AND，必备特征全部 AND；随机结果来自有限目录内的完整 Artwork。点击后弹窗立即打开并开始动效；后台准备同一结果资源时，等待卡/候选卡可滚动但不能提前停止或揭晓。失败不换作品、不放宽条件。用户文案不显示“冻结”“校验”“source”等工程状态。
5. 一个活动 dialog，详情／随机／参考图内容替换并可返回；保留焦点、滚动、筛选与原结果。关闭取消资源、timer、RAF；迟到回调不更新新会话。
6. 默认透明原图下载原字节，核实 MIME、hash、尺寸、alpha 与画面；UI 底色不进入输出，无脚底阴影团。不支持的动作／动画／目标资源无虚假按钮。
7. 参考图仅描述和条件式模板 Prompt，图片由用户在 ChatGPT 上传；不冒充视觉分析或自动发送。打开时预填 Prompt，失败提供全文与手动链接。随机桌面为一排六张 5:6 卡，手机突出当前卡并露出邻卡；六槽为角色风格、外形五官、配色材质、衣物、配饰、道具。抽取前/进行中不显示硬锁条件面板，结果后可展开 Feature AND 锁定供下一抽；不允许任意独立重抽或组件穿戴。普通动画和主动跳过均在六卡全停后经过约 900ms 的 `awaiting-reveal` 边界才显示角色；`prefers-reduced-motion: reduce` 下以静态六卡等待用户点“揭晓伙伴”，不能直接进入结果。结果顺序固定为六项摘要→完整角色→名称/简短说明→复制 Prompt/下载图片→再来一款/详情/ChatGPT 次级操作；手机摘要在角色图上方使用横向轨道，移动重抽复位真实滚动容器。不得滤色或改变 Artwork 原图颜色。详情精选标签按语义优先级选择 4–6 个，仅显示值，桌面置于右侧信息栏，手机置于完整大图下方；搜索索引/文件规格分离，主操作前置，移除棋盘格。打开详情或进入画廊／游戏时，初始焦点落在静态 `#overlayTitle`、`#galleryTitle` 或 `#gameTitle`；标题不呈现输入框外观，可交互控件仍须保留清晰的 `focus-visible` 状态。
8. 新制角色与特征材料必须符合身份：Dots 柔软短绒；Grok Bot 软几何和成对胶囊眼，不是屏幕脸；Meta Muse 奶油包覆形体与内嵌脸面。已有批准PNG按具体版本与范围保留；未得到用户材质裁决时不静默改图或扩大批准。
9. Artwork 可登记 `revealVisuals.style/appearance/paletteMaterial/clothing/accessory/prop` 六类资源，供特征揭晓与说明，不参与组装。生产默认不得使用原图 `sourceRect` 裁片；裁片只作内部制作辅助。Style 可使用已登记的真实 Artwork 识别图，其他非空维度使用独立、语义准确的登记资源；`none`/`notApplicable` 使用统一低强调空值卡。缺资源时保持视觉验收待补，不以粗糙占位图或工程检查关闭；素材存在和用户美术批准分开记录。用户复核预览可展示 `candidate-preview`，但其 `artApproval=pending`，不扩展既有15张已批准 Artwork 的批准/发布范围。
8. 普通 PNG 不等于 Dot/Pet 安装包。目标资料绑定端／版本／来源／查询时间；无目标实装证据标待验证。首期不制作 Pet 包。
9. 审查实际页面桌面及 320、390、768 CSS px，记录源/cache与资源 hash；模拟视口不等于实体手机，构建或脚本不等于艺术批准。
10. 用户确认具体版本后才能记录新页面艺术批准，不自动接受截图基准；旧记录不可重写，取消任务不改通过。
11. 保留 Site 身份、访问范围、批准美术、来源和历史。旧运行/测试非发布保存；窄范围清理，不能清空 dist。
