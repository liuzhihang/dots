# 设计实现与验收规则

- 以 `openspec/specs/` 的当前主规范作为行为和能力边界，以 [`DESIGN.md`](../../DESIGN.md) 作为视觉参考索引；新增产品约束先进入适用的 OpenSpec change，避免在多份指南重复维护。
- 实现前对照 D01 的对应面板与实际素材；按桌面主稿和手机补充稿分别判断，不把整页拼版直接当作目标页面。
- 不虚构作品、标签、能力或批准状态。Artwork、原图/展示资源、Template、Prompt、Draft 和审批各自保留真实身份、用途与版本关系。
- `dist/` 是源码与发布树的混合目录。只按发布 manifest 精确调整闭包；历史源码、已批准原图、来源/hash 和冻结验收原文均需保护。
- 真实浏览器中验证双语、相关视口、键盘/焦点、触控命中区、对比度、动效降级及受影响的复制/下载/导出路径。模拟、构建和单测不能代替视觉、美术、设备或线上验收。
- 新建 QA 原始输出写入 `.artifacts/`；精选发布摘要放在 `design/releases/`；已冻结验收记录不改写。未经本轮明确授权，不提交、发布、改访问范围或归档 OpenSpec change。
