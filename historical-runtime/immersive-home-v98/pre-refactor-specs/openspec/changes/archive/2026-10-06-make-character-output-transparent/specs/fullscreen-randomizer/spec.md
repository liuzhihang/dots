# Spec Delta

## ADDED Requirements

### Requirement: 随机角色结果必须保持透明且不抽取背景
随机候选 SHALL 只由角色模板、颜色/材质、穿搭、配饰、道具和姿态等真实受支持内容组成，不得创建背景槽位、背景阶段或背景颜色候选。预解算、缩略图揭晓、活动结果 Canvas、应用结果和 PNG 导出 SHALL 使用同一透明角色图像。历史 v2 背景元数据可随当前作品保留，但 MUST NOT 进入候选决策、Prompt 或图像。弹窗卡片和按钮等网页 UI 背景不属于角色画布，保持现有呈现。

#### Scenario: 随机抽取和应用角色配方
- **WHEN** 用户从任一入口抽取一个真实可渲染随机配方
- **THEN** 候选和最终角色 Canvas 均保留实际透明 alpha，不出现背景滚轮阶段，应用结果的 Prompt 与角色 PNG 不含历史背景设定

#### Scenario: 随机结果使用历史背景元数据
- **WHEN** 当前合法 v2 作品携带 `studio` 或 `solid` 背景字段并启动随机流程
- **THEN** 字段只作为原项目元数据保留，不被抽取或绘制，随机候选仍为透明结果；取消时原项目及其元数据不变
