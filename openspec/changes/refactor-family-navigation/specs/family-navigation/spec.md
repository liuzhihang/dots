# Spec Delta

## Purpose

定义用户如何在 Dot Icon Studio 的五个独立角色家族中浏览与搜索，并在桌面或移动端切换家族时找回之前编辑的配置和创作状态。

## ADDED Requirements

### Requirement: 导航必须提供五个独立家族入口
系统 SHALL 在首页和工作台提供一致的 Dots、Grok Bot、Meta Muse、人物、动物家族入口。入口 SHALL 清楚标识当前家族；用户选择“全部”时只浏览这五个家族，不能将其解释为另一个角色家族。选择入口 SHALL 定位或打开相应家族，并保持首页/工作台中的当前选择同步。

#### Scenario: 从首页卡片进入家族
- **WHEN** 用户在首页选择 Dots、Grok Bot、Meta Muse、人物或动物卡片
- **THEN** 工作台定位到同一独立家族并显示该组当前角色；页面导航和家族卡片同时更新为相同的选中状态

#### Scenario: 从工作台切换家族
- **WHEN** 用户在工作台选择另一家族入口
- **THEN** 当前选中家族更新为所选组，该组显示自己的基准与适用编辑项，其他家族仍可单独返回

#### Scenario: 浏览全部家族
- **WHEN** 用户选择“全部家族”或清除当前家族过滤
- **THEN** 页面展示五个独立家族，家族数量仍为五，家族身份与基准候选不合并或扩增

### Requirement: 搜索必须定位到现有家族或基准
系统 SHALL 允许用户按五组基准候选的名称、家族名、说明、身份特征、材质和配饰词汇检索。搜索范围 MUST 限于当前应用已登记的五组和基准资料；搜索 MUST NOT 创建新预设或把匹配文案误当成图像生成请求。用户选择搜索结果后 SHALL 聚焦对应家族与基准。

#### Scenario: 搜索已登记的家族特征
- **WHEN** 用户输入一个已登记基准说明中的家族名、材质或配饰关键词
- **THEN** 结果显示匹配家族与现有基准，并允许用户选择该结果进入工作台

#### Scenario: 搜索没有匹配项
- **WHEN** 当前查询没有匹配任何已登记家族或基准
- **THEN** 页面显示清楚的无结果状态和清除查询的操作，当前角色、家族、创作模式及未完成编辑保持不变

### Requirement: 家族导航不得丢弃已编辑配置和创作状态
在同一页面会话中，系统 SHALL 在家族切换、搜索过滤/清除、导航首页与工作台之间保留每组当前已编辑角色配置，以及当前 Artwork/Composer 模式、参考图文字与保留选项、额外 Prompt 文字、输出设置。返回先前家族时 MUST 恢复其先前状态。仅切换家族时不得将未提交编辑静默重置为另一组预设。该行为 MUST NOT 更改现有角色 VERSION 10 或项目 JSON 格式；跨页面刷新后的持久化继续由现有项目保存能力负责。

#### Scenario: 切换后返回原家族
- **WHEN** 用户编辑 Dots，再切换到 Meta Muse 并编辑，然后返回 Dots
- **THEN** Dots 的编辑值和创作状态恢复，Meta Muse 的编辑值也保留在该组当前会话状态中

#### Scenario: 搜索或切换显示状态
- **WHEN** 用户输入/清除搜索、切换“全部/某家族”过滤，或在首页和工作台间来回
- **THEN** 当前角色字段、参考图文字、创作模式及输出设置均不因导航动作丢失或被重置

### Requirement: 移动端导航必须可触达且保持页面视口稳定
在 320 px、390 px 和 768 px 视口，五家族入口、搜索、当前选中状态和主要家族卡片 MUST 能通过触控或键盘访问。若窄屏家族标签使用内部横向滚动区域，页面自身 MUST NOT 因此产生无法控制的水平溢出；搜索和无结果反馈 MUST 在移动端保持可见。

#### Scenario: 在窄屏切换家族
- **WHEN** 用户以 320 px 或 390 px 宽度触控或用键盘浏览家族导航
- **THEN** 五个入口可以逐一到达，当前选中家族可辨识，页面其他内容不会被屏外导航遮挡

#### Scenario: 在平板上搜索家族
- **WHEN** 视口为 768 px 且用户通过导航搜索家族或特征
- **THEN** 输入、搜索结果、工作台定位与状态标识可读可用，页面保持正常滚动且无需横向拖动整个页面
