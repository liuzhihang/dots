# Design

## Context

背景与动机见 [proposal.md](proposal.md)，可观察行为见 [family-navigation spec](specs/family-navigation/spec.md)。应用是原生 JavaScript 单页编辑器，只有一个活动项目，并有五个稳定的家族 ID。当前家族控件位于检查器中；首页与编辑工作区将在视觉上由 `refresh-studio-visual-design` 分开呈现。现有角色模型与项目 JSON 只存储一个活动角色，因此保留五组草稿状态不得通过更改该文档格式来实现。

## Goals / Non-Goals

**目标：**

- 在首页和工作区中提供相同的五家族控件。
- 仅搜索现有五个家族及其各自唯一的当前基准描述。
- 在家族间切换时，保留用户在当前会话中对各家族所做的编辑、参考文本、创建模式和输出选项。
- 确保桌面、平板和移动端导航均可操作，且不引入独立的页面路由器。

**非目标：**

- 不添加家族、基准预设、在线搜索服务、基于账户的收藏或新的持久化格式。
- 不负责首页/工作区视觉系统或随机化状态机；与各自独立的 change 协同。
- 不将搜索词或家族切换转化为生成操作，也不以此破坏性地替换配置。

## Decisions

### Use stable family identity as the single navigation key

每张卡片、导航项、搜索结果和工作区标题均使用现有稳定家族 ID 及其唯一显示名称。首页和工作区控件调用同一个选择操作，并读取同一份已选家族状态。“全部家族”是概览/筛选状态，不是第六个 ID。这样可以避免主视觉卡片与编辑器控件显示不一致。

**备选方案：** 分别维护页面级已选家族和工作台家族。未采用，因为这会允许卡片显示一个家族，而编辑器显示另一个。

### Keep an in-memory project draft per family for the active page session

切换家族前，保留当前项目快照，包括家族专属角色配置和创建字段。首次进入另一个家族时，载入该家族当前的基准/默认项目；在同一页面会话中返回该家族时，恢复对应快照。搜索和筛选操作只改变可见结果；除非用户选择结果，否则不修改活动项目。这样可以在不更改既定的 VERSION 10 角色或项目 JSON schema 的前提下保留有意义的编辑。现有导出/导入流程仍负责跨重新载入保存单个活动项目。

**备选方案：** 将多家族集合强制写入项目 JSON 或 session storage。未采用，因为用户没有要求多角色文档，而且更改项目契约超出了导航重构的范围。仅保留于当前会话的草稿映射即可满足导航状态保留要求，并维持现有导出行为。

### Search the registered family and baseline metadata only

先统一大小写并规范空白字符，再将查询与家族显示名称以及各家族唯一基准候选的精选元数据匹配。搜索结果指向现有家族/候选项。无结果提示应提供明确操作，且不更改当前草稿。内容索引保持本地且精简，不作为全站搜索。

**备选方案：** 搜索所有旧预设和每一项编辑器设置。未采用，因为旧预设属于兼容性数据，并非获准的新候选项；将它们显示出来会破坏“每个家族仅有一个基准候选”的门槛。

### Keep the filter and search operable at touch widths

桌面布局在首页/工作区外框顶部附近显示家族栏和搜索框。窄屏上，搜索框占满可用宽度；五项家族栏放在独立的触控滚动行内，或在空间允许时换行；家族卡片采用清晰易读的堆叠/网格布局。提供明显的焦点、选中状态、标签和结果数量，并确保内部可滚动家族栏不会造成页面级横向溢出。

**备选方案：** 将所有家族控件收纳进无标签图标菜单。未采用，因为这会隐藏五个独立身份，并使当前家族难以辨认。

## Risks / Trade-offs

- [完整重新载入后，家族的页面会话草稿会消失，除非用户先导出] → 明确该边界，并保留现有单项目 JSON 保存/导入流程；不得暗示导航映射是云端或持久化存储。
- [搜索家族描述可能返回含糊的匹配结果] → 每项结果均显示家族名称，且只在用户明确选择结果后才切换家族。
- [首页和工作区可能分阶段交付] → 两处使用同一选择 API；某个界面尚未挂载时，保留当前稳定家族选择，直到该界面可用。
- [触控滚动导航可能被误认为页面溢出] → 在实际浏览器中测试 320/390/768 px 宽度，并确保只有导航栏可横向滚动。

## Migration Plan

1. 将现有家族控件移入共享导航组件，并添加一个共享的已选家族操作。
2. 添加本地元数据搜索和内存中的家族草稿映射；保持当前项目 JSON、VERSION 10 和旧资源 ID 不变。
3. 将 `refresh-studio-visual-design` 中的首页卡片和工作区家族控件接入该组件；在真实浏览器中验证家族切换、搜索、无结果恢复以及返回首页流程。
4. 验证 320 px、390 px、768 px 和桌面布局、键盘操作、状态保留以及现有配置导入/导出。仅作为已获授权的现有 Site 候选版本的一部分发布，并沿用现有 Site 身份和访问设置。

## Open Questions

无。草稿明确仅保留在当前页面会话中；现有活动项目导出/导入流程仍是持久化机制。
