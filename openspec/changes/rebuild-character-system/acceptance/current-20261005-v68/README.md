## 修复前快照与限制

这批帧是在 Dots 已知缺陷修复前记录的：绒面仍有可见颗粒，部分动作效果会削弱主体本身的视觉存在感。它们仅用于定位和比较渲染行为，不能混入后续修复后的结果、用作最终版本代表，也不能据此声称 Dots 已通过材质或动作美术验收。

矩阵中的 3D/WebGL/CPU 画面属于保留的**结构诊断路径**。用户主工作台展示静态内置形象和受支持的 2D Canvas 合成；未由当前模板配方支持的设定只影响 Prompt，并不会因此变成已渲染结果。诊断画面、自动矩阵、独立效果图、构建结果和任务勾选都不能替代实际工作台页面美术验收。未来若将真实 3D 作为成品交付，仍须满足原有 WebGL/CPU、多视角、动作、比例及配饰接触合同。

320/390/768 px 浏览器视口与实体手机验收分别记录；浏览器缩放不代表实体设备通过。角色身份和材质的视觉判断、人物/动物原创性审核及用户逐组确认也不能由矩阵脚本代签。人物与动物不得使用动漫截图像素、抠图、贴图或完整角色复刻；允许保留的软件原版身份须标明来源。

冻结与提取护栏的本地结果见 [evidence-guards.json](evidence-guards.json)：已存在快照拒绝覆盖、快照文件哈希未改变、子集矩阵拒绝均为通过。README 暂不列最终 `sourceId`；该标识须以之后核验的最终快照为准。
