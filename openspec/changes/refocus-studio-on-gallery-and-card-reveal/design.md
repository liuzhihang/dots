# Design

## Context

动机与产品取舍见 [proposal.md](proposal.md)。本规划基于 main/`64db8f6cdfbda76f0f3851e63d5b4ec1c73e8592`、cache 86，本轮图 1 附件、当前 Chat 可读的方向切换后五轮，以及本会话对参考图文字模板 / 首期无 Pet 包的明确确认。材料、查询时间和未读历史边界见 [输入与原型附表](planning/evidence-and-prototype.md)。

当前 `dist/index.html` 与 `studio.js:1-18` 将图库、项目 v2、角色 VERSION 10、组合 resolver、Canvas、Shared2D 和 `live-runtime.js` 静态连接；`studio-home.js` 还通过组合目录取得批准状态。详情的 Prompt 经 `createLookCharacter → makeProject → buildCreationPrompt`；随机候选必须带 project/composition/render plan，最后组装并应用工作台。已有 typed tags、真实 PNG、资源校验、取消与逐阶段动画可复用，但数据及动作必须解除这条调用链。

Vite 以 `dist/` 为根；这里同时存放可编辑源码、旧编辑器、QA 页面及发布文件。当前 build 只生成 Three bundle。15 张登记成品的当前 hash 与 v83 冻结源文件相同，人工批准有独立记录；另 5 张静态姿态有工程登记，批准范围尚未映射。此阶段不改现行规则、主规范、源码和素材，所有实施变动由后续 apply 执行。

## Goals / Non-Goals

**Goals:**

- 所有发现、详情、复制与下载围绕稳定作品/资源版本；一个候选模型服务首页弹窗和游戏页。
- 页面状态、overlay 状态和抽取快照分离，结果切换与异步任务有明确生命周期。
- 保留图 1 构图与批准美术，使用真实 DOM/UI；首期内容由已有合格完整作品构成。
- 目录可增量扩充，新作品和标签无需组件适配或复制页面。
- 发布资源真实、能力标识准确，工程/内容/批准/目标验证/部署分别记录。

**Non-Goals:**

- 不保留工作台、运行时换装、旧项目文件 reader、恢复/迁移/别名或新旧双模式。
- 不新增后端、视觉 API、账户、公共图像上传、审核系统、3D 或 Pet 包制作。
- 不用批量新角色、每种姿态齐备、目标平台安装成功作为基础图库闭环前置条件。

## Decisions

### 1. 保留现有前端技术，重划依赖边界

保留原生 ES modules 与 Vite。新入口只协调作品目录、查询、页面、overlay 和抽取视图；不为此引入框架、数据库或服务端。替代方案是框架迁移或保留旧工作台做中间层：前者增加无关范围，后者持续保留已退出合同，均不采用。

建议文件边界（可在 apply 中按现有命名微调，但依赖合同不变）：

| 模块 | 职责与允许依赖 |
| --- | --- |
| `dist/studio-artwork-catalog.js` | Artwork、Asset、Prompt、身份关系、目标资料的可信静态目录；不导入角色模型/组合模块 |
| `dist/studio-tags.js`、`studio-tag-browser.js` | 纯查询及标签 UI；显式逐作品关联，不由结构 family 推导渲染能力 |
| `dist/studio-draw.js` | 资格、硬条件、选取、去重、冻结 DrawResult；纯逻辑，不依赖 DOM、Canvas 或渲染器 |
| `dist/studio-asset-loader.js` | 登记路径、MIME、hash、尺寸、解码、取消与 objectURL 生命周期；所有下载/预载共用 |
| `dist/studio-prompt.js` | 作品版本 Prompt 与参考模板；不从项目配置生成 |
| `dist/studio-overlay.js` | 单一原生 dialog 的替换、返回、焦点、Esc、滚动恢复 |
| `dist/studio-detail.js`、`studio-reference.js` | 详情与参考图文字视图，操作输入均为显式快照 |
| `dist/studio-game.js` | 游戏页默认有效池抽取会话，复用 draw 与揭晓视图；本 change 不提供范围控件 |
| `dist/studio-fullscreen-random.js/.css` | 提取并改造为共用卡片呈现，去除组合 adapter、组装和工作台应用 |
| `dist/studio-home.js`、`studio-scenes.js` | 已批准 Hero/专题艺术与导航入口；去除编辑器示例 |
| `dist/studio.js`、`index.html` | 精简页面协调、导航、错误提示与入口；不保留工作台 DOM 或静态旧模块导入 |

详尽路径与旧测试映射见 [清理附表](planning/cleanup-and-spec-map.md)。`src/live/`、生成 bundle、旧编辑器/兼容桥/QA 面板从发布树退出；有历史价值的工具或组件文件移至明确非发布路径，或从工作树窄范围删除后由 Git 历史保留。批准原图、来源、冻结证据不随代码清理删除。

### 2. 以 Artwork 发布资源代替 CharacterProject

可信目录在加载时校验唯一 ID、完整引用、资源版本、Prompt 版本、特征完整性及批准来源；浏览和抽取读取相同目录快照。使用简单静态数据结构即可，不保留项目 schema 作为“兼容元数据”。替代方案是给旧 Project 加 Artwork 模式，仍会依赖 parse/fit/render plan，因此不采用。

| 实体 | 必要字段／约束 |
| --- | --- |
| Artwork | `id/title/description/source/publicationStatus/styleIdentity/tagIds/features/assetRefs/promptRefs/variantGroupId/targetResources`；完整作品才可发布 |
| Character / variantGroup | 可选稳定 ID 和明确批准的成员关系；颜色相似、同物种或同风格不自动等于同角色 |
| Tag | `id/dimension/label/aliases/status/source`；风格、对象、系列、配色、形状、配饰、道具、动作、表情、背景类型、用途等有真实内容才显示 |
| Feature | 事实值、词条 ID、可选示意资源、来源；配饰/道具列表明确 `none`，未核实为 `unknown`，不得编造 |
| Asset | `id/version/path/mime/byteSize/sha256/width/height/alpha/resourceKind/sourceRef/engineeringValidation/artApprovalRef`；缩略图、原图、姿态、动画、目标包各自独立 |
| Prompt | `id/version/artworkId/assetVersion/language/text/styleTemplate/targetIntent`；真实图像描述与期望后续新增内容分开 |
| TargetProfile | `platform/client/version/format/dimensions/alpha/frameLayout/states/sourceUrl/queriedAt/verificationStatus`；资料不是已验证输出 |
| DrawResult | `drawId/catalogRevision/artworkId/assetRef/promptRef/querySnapshot/requiredFeatures/revealFeatures/poolFingerprint`；冻结后不得读取另一活动作品 |

`publicationStatus`、文件存在、资源工程可用、人工美术批准、目标端验证和部署分别记录。入池需发布状态有效、完整角色资源已登记并通过工程检查、Prompt 和事实特征齐备、人工批准覆盖该具体素材；目标用途条件还需相应支持状态成立。无可靠来源或批准的内容留在非发布盘点，不借旧组合的工程成功进入图库。

15 张原有成品先关联 v83 的具体批准与匹配 hash，不重新制作或自动重写历史状态。5 张姿态已经存在于 v83 冻结 source 并登记为当时 state slots；确认记录只逐项列出15个 Artwork ID，同时提到已登记状态，所以姿态批准范围未完成逐文件映射，不能断言已批准或被否决。先核对旧审查证据，无法确认覆盖时保持非发布候选，单独确认后再发布；缺变体时详情展示“暂无已发布变体”。机制测试可使用隔离测试目录，但测试 fixture 不能成为发布批准。新建/导出主流程默认透明角色，scene illustration 是另一资源类型，默认角色池不包含场景插画。

### 3. 首页视觉与功能语义分别处理

图 1 是布局及玩法参考，不是整页可部署图片或角色资产许可。保留品牌、中央标题、左右群像、现有专题场景及浅色卡片；所有文字、按钮、卡片、滚动和弹窗由组件实现。原“自由搭配/开始创作/工作台”宣传改为精选、真实动作系列或参考图入口，避免额外扩张宣传长页。

首批五组专题映射目录查询，不构成固定 family 渲染结构。图库 Dots 蓝色短绒/软椭圆眼与首页紫色展示 Dot 可作为已批准的不同资产范围存在，不互相替换。图 1 示例中的嘴、脚、屏幕脸或玩偶形象不覆盖既有身份。替代方案是重新批量绘图或将首页削成搜索按钮，均违背已确认视觉方向。

### 4. 三页导航和单 overlay

新 hash 路由为 `#home`、`#gallery`、`#game`，画廊查询可以编码为稳定查询参数。未知路由统一回首页；未知/损坏查询给出可恢复错误或无结果，不静默扩大随机范围。`#workspace` 不特殊映射，旧 JSON/存储不读取、不迁移，也不执行清除。

| 状态 | 内容 |
| --- | --- |
| PageState | 页面、画廊查询、页面滚动、最后卡片焦点；无角色草稿或撤销栈 |
| OverlayState | `none/random/detail/reference`，当前内容快照、返回描述、触发点；同一时间仅一个模态 dialog |
| DrawSession | 条件、运行标识、阶段、AbortController、已完成 DrawResult；与视图容器分离 |

首页/画廊随机按钮打开 modal；游戏页内嵌同一揭晓视图，游戏页的全局随机入口也使用同一 modal adapter。一次只允许一个活跃抽取：打开其他容器前中止未完成会话，不另设第二算法或静默重抽。游戏页已完成结果可留作返回摘要。

画廊 → 详情 → 参考图在单 dialog 内替换视图，关闭／返回按来源恢复；随机结果 → 详情 → 返回仍引用同一个 DrawResult；游戏 → 详情关闭恢复结果。浏览器 Back 先退出当前 overlay/返回描述，再回页面导航；Forward 只恢复已保存的安全内容快照，不重启抽取或上传。所有状态只引用当前可信目录 ID，不能从 URL 注入路径/Prompt。

打开时记录触发按钮和背景滚动，背景 inert；替换内容保持焦点陷阱但将焦点移到新标题/主要操作，关闭恢复触发点（若已不存在则回页面标题）。更多筛选使用非模态 disclosure，或占用同一 overlay 槽位，不能与详情形成第二层模态。移动端 dialog 全屏，关闭和主要操作始终可达。

替代方案是每个功能单独 dialog；其焦点、Esc、返回和异步生命周期容易竞争，故不采用。

### 5. 完整作品先选定，多卡片后揭晓

顺序为资格校验 → 普通查询 → 硬锁定 → 去重选择 → 冻结 → 预载 → 分槽滚动 → 顺序停止 → 成品。暂不做各维度独立随机或逐阶段收窄算法；前者可能没有可命中作品，后者增加证明与边界成本。

普通标签查询为同维 OR/跨维 AND，与规范化关键词求交。硬锁采用 `requiredFeatures.every(feature => artwork 包含 feature)`；例如锁眼镜与耳机必须同时存在。锁定是检索约束，不是让组件固定在任意角色上。未知锁定 ID/维度作为错误或无匹配，绝不自动忽略。

cache90 固定六个揭晓位置：角色风格、外形五官、配色材质、衣物、配饰、道具。底层八类特征为角色风格、外形、五官、配色材质、衣物、头部配饰、身体饰品、随身道具；头部配饰与身体饰品在配饰卡合并呈现。动作/表情为选中作品后的已制作变体或实际动画资源；背景是资源规格，二者都不占卡槽。unknown 不作为默认候选；核实为 none 或 notApplicable 的卡片准确表达后快速停止。

本轮选定的 `Photo 1.jpg` 是实际取得的整页主参考。九张附图、辅助随机材质图及 sandbox ZIP 未从当前会话返回，不能声称看过其中像素；本 change 不引用它们作为已审核视觉依据。cache90 的桌面固定为一排六张 5:6 竖卡，手机用横向轨道突出当前卡并露出邻卡。只展示池内真实特征，全部停止后展示完整 Artwork 与 Prompt。结果以复制 Prompt 和下载图片为主操作，再随机、详情、ChatGPT 为次级。

相邻滚动样本可来自当前有效池中不同作品的真实特征和有来源的示意资源；每项绑定自己的 source Artwork、Asset 版本/hash 与 sourceRect，并只作为滚动过程线索，不能冒充最终结果或可安装配件。特征示意优先使用登记原图的可追溯缩略呈现/细节和通用 UI 图标；不从展板、网页截图或动漫截图提取角色像素。不能为丰富轨道编造不在图库中的内容。最终每张停卡必须来自唯一冻结 DrawResult；完整结果图、标签、Prompt 和下载也必须来自同一快照，且仅在全部停卡后显示。

DrawResult 冻结 Artwork、原图/hash、Prompt 版本、条件和真实揭晓值。语言或目标 Prompt 切换也仍引用该作品；未来新增要求单独标明为创作意图。预载在离屏校验结果原图和所有轨道必需资源，失败不进行虚假抽取。

| 阶段／边界 | 处理 |
| --- | --- |
| ready → selecting | 冻结当前条件；重复点击不并行启动；动画中条件更改只作用于下次 |
| 空池 | 动画前列出冲突/资源原因；只允许用户主动调整；不清锁、不偷偷换图 |
| 单候选 | 明示“一款符合条件”；短揭晓或跳过，允许重复但不谎称去重 |
| 去重 | 按规范化条件＋目录版本＋候选成员指纹维护会话抽取袋；多候选先避开近期项，耗尽后明确重置，尽量不连续命中上一款；硬筛选永远优先 |
| preloading | 按冻结资源校验本地登记路径、MIME、hash、尺寸、解码；加载失败进入 error，重试同一资源或用户另行抽取，不替换冻结作品 |
| revealing | 每槽独立动画，前一槽停止后下一槽停止；停值不可变化；隐藏完整结果操作 |
| result | 卡片收为特征摘要；复制 Prompt、下载图片为主操作，再随机、详情、ChatGPT 为次级；按需展开锁定区将真实 Feature 作为下一次抽取的 AND 条件；不提供“应用组合”或单卡重抽 |
| 失败时有旧结果 | 保留旧结果只读并明确标为上一款；本次失败与旧结果不混合，不显示旧图配新 Prompt |
| 跳过/reduced-motion | 完成必要预载后原子停止各槽并显示同一结果；不跳过资格或资源校验 |
| cancelled/关闭 | abort、清 timer/RAF、解除事件、回收临时 objectURL；session/run token 使迟到完成无效 |
| 快速重开/换容器 | 新会话标识；旧会话不能写 UI、剪贴板或结果；只有显式新抽取开始下一次选择 |

### 6. 详情、变体、复制与下载共用冻结引用

详情大图下方展示值标签，不显示风格/背景等维度前缀；图像表面使用干净浅色，不显示透明棋盘格。对应中英文 Prompt 与操作构成次级区域；不跳入编辑页。变体选择只能切到同一明确身份关系下已发布的完整 Artwork，原子更新图片、标签、Prompt、下载与目标标识；加载期间禁用针对尚未成功显示的新版本操作。没有可用动作不生成占位图。

下载读取原图登记字节，通过同一 asset loader 校验并导出准确文件名；不使用浏览器 Canvas 重绘已有原图。若未来需要别的尺寸/格式，只展示实际登记并验证的派生资源。本期不自动制作目标包。复制冻结当前 Prompt 文本，失败显示可选全文及 TXT；快捷打开在用户点击上下文打开 `https://chatgpt.com/?prompt=...`，URL 使用当前冻结全文；已在参考站跳转后的真实 ChatGPT 输入框核实预填且等待用户发送。复制为备用，入口失效时手动粘贴，参考图在 ChatGPT 上传。弹窗被拦截显示手动链接，无法联网保留已复制文本；不能检测或承诺新窗口已完成生成/发送。

替代方案是详情、随机、图库各自维护导出状态；会产生版本混配，故统一操作输入。

### 7. 参考图：文字模板与 ChatGPT 手动上传

本轮用户补充取代早先 A 的站内本地预览：本站只提供描述、保留项、风格和语言模板，不选取、预览或分析图片。作品详情带入当前风格，全局入口无需先选作品，仍是单 overlay 次级辅助操作。

Prompt 明确“如果在 ChatGPT 上传了参考图片，则参考该图片并保留用户要求”；没有图则按文字和模板创作。本站不接视觉服务、不上传图片、不新增账号或公共记录；用户在 ChatGPT 附图并自行发送。只保留复制 Prompt 与在 ChatGPT 中创作主操作，失败有全文与携带同一 Prompt 的手动链接。描述在本次 overlay 会话内存保存，关闭整段会话后清除，返回详情后可恢复。

该预填入口的当前浏览器行为由实测支持，未据此宣称稳定官方 API 或所有端保证；保留备用剪贴板和可选全文。当前所有站内输入均不默认发往外部，只有用户点击创作时将模板文本带到 ChatGPT。

### 8. 目标资料与实际资源分离

资源类型分为 transparent-character-still、still-variant、animation-preview、sprite-sheet、target-package、scene-illustration。页面/card surface、作品文件背景、目标平台 alpha 要求是三个独立字段。静态图不因动作标签变成动画；滚卡动画也不代表角色动作文件。

本期 TargetProfile 只提供官方资料、端/版本、查询时间及待验证项，实际 export 仅针对存在的登记资源。Web Pet 官方要求与本机 v1/v2 插件合同分开引用，不能把本机帧布局说成所有端官方标准；Dot 文档没有任意 PNG 导入合同。首期没有 Pet 包，不显示安装/包导出按钮；扩充需新范围和目标环境验证。[素材与目标附表](planning/content-and-targets.md) 记录具体已确认事实。

后续作品可以覆盖待机、思考、执行、等待、受阻、完成、阅读、睡觉、聆听等，但不要求本期凑齐。Grok 点列/液滴方向按明确身份及真实文件保留；不要用静态拼贴补成动画，也不为 Pet 状态随意镜像改变方向。未来目标资源必须按实际端状态/帧合同独立制作、播放和验证。

## Risks / Trade-offs

- [现有素材表 `unreviewed` 与后来人工确认不同步] → 新目录引用匹配 hash 的确认记录，保留历史冻结字段，不整批覆盖状态。
- [只有 15 个合格作品且多数无变体] → 真实显示范围、单候选/重复与暂无变体；先交付发现闭环，不用未批准动作补库存。
- [特征卡示意不足] → 登记可追溯缩略信息和“无”值；不能生成假成品或把组件适配作为前置。
- [旧规范重复要求工作台/项目/首页完全冻结] → 11 个旧 capability 同时给出 delta；同步预演检查旧要求副本与 Purpose，主规范当前不动。
- [旧 QA 与编辑器仍在 Vite 的发布根] → 精确清理 manifest、生产模块图和发布文件允许清单双检；不可只删导航而继续发布入口/资源。
- [Chat 起始历史与辅助图不可完整读取] → 记录读取边界，按实际可读用户决定及本轮完整附件规划，不推断旧美术/能力确认。
- [目标格式会变化且没有目标环境实测] → 存 queriedAt/来源/verificationStatus，实施显示前复核；首期不承诺安装。
- [构建或截图被当成艺术批准] → 验收账本分状态，新增页面由用户确认具体冻结版本，禁止自动接受截图基准。

## Migration Plan

此节是源码退出与交付顺序，不是旧数据迁移。一个主 change 顺序为 M1 → M2 → M3 → M4 → M5；M4 的纯 Prompt/模板工具可在 M2 后开发，但完成验收依赖 M3 的冻结结果一致性。

1. 锁定本次源码/既有未跟踪文件基线，建立作品与清理清单；提取有效资源、安全、Prompt 与取消工具，旧工作台链退出；不读取、删除或迁移用户旧存储。
2. 实现三页导航、图集与单 overlay 详情，保留原场景艺术；旧模块不作为暂时的产品兼容模式发布。
3. 接上共用 draw/reveal controller，完成边界和冻结一致性，再接条件式参考图模板与目标说明。
4. 替换测试与文档，完成新范围实页/下载/模块图检查。主规范在获授权的 sync/archive 环节按 delta 更新，并重写旧 Purpose；归档不重写历史证据或将取消项改成通过。
5. 产生全新的 `design/acceptance/current-<本机日期>-v<cache>/`，绑定源码、资源 hash、页面、下载和人工确认；验收文件夹不存在才创建，不复用本轮已有历史目录。
6. 用户确认本地候选预览后另行决定提交/发布；保持原 Site 身份与 owner-only 设置。Git、保存 Site、部署、页面读回、实体设备分别验收。

若实施需要回退，只恢复本 change 精确文件集合或使用 Git 的可审查反向提交，不执行整目录清空、`reset --hard`、`git clean`，不波及素材/来源/历史与他人文件。部署回退只在另获发布授权后使用原 Site 的已知版本；本规划不触发任何回退或部署。

## cache89 验收修复决策

QA01–07来自2026-10-07“优化角色与交互”末轮和本会话验收单，当前页面未获签字。采用登记的代码原生SVG特征示意：风格只用批准成图；外形用独立轮廓；配饰/道具用真实词条图标，none明确；动作用姿态提示图和真实表情文字。源为`studio-feature-visuals.js`、稳定id/版本绑定冻结Feature，不是可组装PNG、新角色、动画或已批准变体。缺失映射使用明确文字示意，禁止原图统一fallback。动画态保留滚动邻卡，全停后收为短摘要；先预载风格/成品资源，内联静态向量没有网络依赖。

结果主操作改为再来一款/复制/下载，ChatGPT次级，沿用当前预填URL和用户发送边界。下载捕获Asset原版本，重抽不改下载内容；dispose abort，迟到状态不污染新结果。详情以4–6个精选标签替代原事实全列；检索索引完整，普通规格不做标签。标签点击退出单overlay到图库，返回根页面历史恢复原查询/滚动/触发焦点。标题栏唯一静态h2，初始焦点preventScroll且限定其outline；交互focus-visible不移除。主要复制/下载先于折叠Prompt，无真实版本不显示空段。首页窄屏英文装饰隐藏，宽屏也须防重叠，原美术文件不变。

本站参考图仍仅文字模板，用户在ChatGPT上传；验收单中选择/移除/重复上传项按最新产品能力标不适用，不恢复旧选图能力。真实动作变体、Grok动态状态、动画/Pet包和实体Safari仍缺对应批准/测试环境；使用fixture的工程验证与真实内容验收分列。新candidate/cache89建立证据与录屏，不覆盖cache87/88或历史记录，不sync/archive。
