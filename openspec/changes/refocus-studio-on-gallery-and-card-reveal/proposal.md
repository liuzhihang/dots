# Proposal

## Why

用户发现自由组件组装持续难以达到满意的美术效果，已明确转向高质量完整角色图、标签分类搜索与随机发现；继续维护组件适配和工作台会把投入留在已退出的产品目标上。项目尚未对外发布，现在可以围绕作品重建主流程，保留图 1 的吸引力与已批准身份，取消旧版兼容负担。

## What Changes

- 以本轮附图 1《Dot Icon Studio 角色设计展板》为主要视觉方向，保留中央标题、左右群像、明亮氛围及首批五组专题卡；纠正登录、永久“五大家族”、工作台和虚假现场生成文案。首页、画廊、灵感游戏构成三条导航目的地。
- 引入 Artwork、Tag/Feature、Asset、Prompt、可选身份变体关系、TargetProfile 和 DrawResult。现有 15 张登记成品、typed tags 与查询语义优先复用；配饰、道具、形状、动作是成图事实，不是可穿戴组件。已有工程可渲染但未批准的模块组合不会自动成为发布作品。
- 将详情、复制、原图下载及随机结果直接绑定作品版本。已有姿态文件按真实资源及确认范围登记，未制作动作只作明确的后续创作要求，不伪装成动画。
- 首页与画廊使用全局卡片揭晓弹窗，游戏页使用同一候选模型、状态机和卡片视图。先选有效完整作品，再逐卡揭晓其真实特征；前台固定六卡“角色风格→外形五官→配色材质→衣物→配饰→道具”，底层维护八类事实；动作是独立变体/动画资源，背景是资源规格。全部停止后使用“遇见新的伙伴”结果阶段：宽屏左图右名称/真实规格/简短详情，下方为六项收拢事实摘要及复制 Prompt/下载图片主操作；手机主图居中置顶、事实摘要为横向轨道。Artwork 原图颜色保持不变；不独立抽配件后拼图或放宽条件。
- 参考图按本轮最新确认：本站仅用户描述、保留项及条件式风格模板 Prompt，不选取/预览图片、不接视觉模型。点击携带 Prompt 预填 ChatGPT 并备用复制；用户在那里上传图片与发送。抽取前和动画中无条件面板；结果后可展开 Feature AND 锁定用于下一抽。结果以复制 Prompt/下载图片为主操作，再随机/详情/ChatGPT 为次级；没有 TXT 下载。
- **BREAKING**：删除工作台、项目 JSON 导入导出/恢复、旧模式、专门旧路由兼容、装备及诊断产品入口；组合 resolver、FitProfile、Canvas 组装和 3D 不再进入普通浏览与随机的运行或发布依赖。没有 v1/v2 或旧角色 schema 迁移、兼容 reader、双模式分支。
- 首期不制作 Pet 包、不接外部分析服务、不建设账户/公共上传/投稿/审核。目标资料按端、版本、来源及验证状态展示；普通 PNG 不标为可安装 Dot/Pet。
- 按 M1 目录与退出 → M2 首页/画廊/详情 → M3 共用卡片玩法 → M4 Prompt/参考图/目标说明 → M5 内容、视觉和工程验收交付。M1 建立可信作品与退出合同；M2 用户可筛选、查看并带走成品；M3 可按条件随机发现；M4 可携带参考图要求继续创作；M5 才形成待用户预览确认的完整候选版本。

## Capabilities

### New Capabilities

- `artwork-catalog`：完整作品中心的目录、资源/Prompt版本绑定、事实特征、发布资格及可选变体关系。
- `reference-creation`：按用户文字形成条件式模板 Prompt，图片在 ChatGPT 上传，以及复制/打开 ChatGPT 的边界和降级。
- `target-resources`：静态、动作、动画、sprite sheet 与目标包的分类及端/版本/验证状态；首期无 Pet 包。

### Modified Capabilities

- `catalog-tags`：查询围绕 Artwork，扩展事实特征；解除首页完全冻结与工作台标签合同。
- `family-navigation`：首页/画廊/游戏导航、单 overlay 返回与浏览状态恢复；退出身份草稿和旧项目路由。
- `studio-visual-experience`：按图 1 保留首页视觉，纠正产品能力；真实 UI 与专题入口替代工作台入口。
- `studio-creation-experience`：画廊详情、真实变体和直接操作替代工作台/组合创作。
- `fullscreen-randomizer`：共用作品抽取与多卡特征揭晓，硬锁定、取消、去重、资源失败及结果一致性。
- `character-creation-modes`：退出整图/组合双模式与项目格式，保留冻结资源操作和无账户边界。
- `character-families`：保留首批身份与原创/来源要求，退出运行时家族渲染结构及固定数量假设。
- `character-contact-and-motion`：检查完整作品的真实结构、接触与动作；退出程序化诊断和组件适配合同。
- `character-visual-acceptance`：按作品、资源和实页验收，独立记录工程、批准、目标验证及发布状态。
- `modular-2d-composition`：移除组件登记/解算/换装/项目引用产品要求，约束旧系统退出运行和发布。
- `composition-coverage`：退出组合笛卡尔覆盖、图鉴与项目往返门槛，改为实际发布作品与资源路径覆盖。

## Impact

涉及 `dist/index.html`、`studio.js`、首页/图库/标签/随机模块、素材目录、Prompt/下载工具、页面样式与 `scripts/`；保留 Vite 和原生 JavaScript，移除无用途的 Three 与仅服务旧 3D 的构建依赖。具体复用、改造、删除、退出发布清单见 `planning/cleanup-and-spec-map.md`，里程碑完成条件与证据见 `tasks.md`。

后续 apply 才修改根 AGENTS、DESIGN、设计规则、README、业务源码与依赖；主规范通过明确的增量同步流程调整。本次只写本 change 规划，保留批准美术、来源、Git/归档/冻结证据及原 Site `appgprj_6abf8f3128308191b2f8a2a9c6003704` 的身份和访问设置，不清空 `dist/`。

素材扩充、真实视觉分析、可安装 Pet 动画包需要独立资源制作/服务/目标环境授权，不阻塞首期闭环。历史 Chat 起始段尚不可读，资料边界与已读取输入见 `planning/evidence-and-prototype.md`；最新用户决定已充分确认，没有影响本期范围的待决问题。用户已另行授权将候选发布到原站人工确认；发布不代表新页面艺术批准。
