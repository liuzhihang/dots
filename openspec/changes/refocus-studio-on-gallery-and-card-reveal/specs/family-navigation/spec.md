# Spec Delta

## REMOVED Requirements

### Requirement: 导航必须提供五个独立家族入口
**Reason**: 新主导航为首页、画廊、灵感游戏；把五种视觉身份维持为单独导航目的地会锁死目录架构。
**Migration**: 首批专题卡作为首页内容入口映射到画廊筛选；不迁移 family 草稿、别名或 #workspace 路由。

### Requirement: 搜索必须定位到已登记的家族或内置形象
**Reason**: 该要求仍以 family、角色编辑和旧首页搜索为查询中心。
**Migration**: 从新 Artwork 目录重新建立查询状态，搜索语义由 catalog-tags 和 artwork-catalog 变更规定；不导入旧编辑状态。

### Requirement: 家族导航不得丢弃已编辑配置和创作状态
**Reason**: 旧身份草稿、模式、撤销和项目恢复随工作台退出。
**Migration**: 保留画廊筛选、滚动、当前 DrawResult 和详情返回状态；不迁移角色草稿或旧项目。

### Requirement: 移动端导航必须可触达且保持页面视口稳定
**Reason**: 原验收对象是图库/工作台的家族切换及定制操作。
**Migration**: 320/390/768px 与桌面要求转为新页面、图库筛选、单 overlay 及游戏的可触达性检查；没有工作台目标。

## ADDED Requirements

### Requirement: 主导航必须提供首页、画廊和灵感游戏
用户 SHALL 能从主导航访问首页、作品画廊和灵感游戏。首页首批视觉专题卡 SHALL 打开带有对应标签条件的画廊；画廊不得提供进入工作台、组装或装备组件的操作。未知路由 SHALL 统一回到首页；无效查询可显示可恢复提示。系统不得识别或恢复旧工作台、旧项目或旧 schema。

#### Scenario: 从专题卡进入画廊
- **WHEN** 用户选择首页任一首批专题卡
- **THEN** 画廊显示对应已发布标签的 Artwork，导航仍允许访问首页和灵感游戏

#### Scenario: 打开旧地址或未知路由
- **WHEN** 用户直接打开 `#workspace` 或其他未知路由
- **THEN** 页面回到首页，不自动进入兼容工作台、加载旧项目或声明存在迁移功能

### Requirement: 关闭作品详情必须恢复图库浏览位置和筛选
画廊 SHALL 保留搜索文本、标签/Feature 筛选、排序和滚动位置。打开 Artwork 详情后关闭、浏览器返回或使用明确返回操作 MUST 恢复离开时的画廊状态与触发卡片焦点；详情内变体选择不改变原画廊查询。重新进入画廊时，仅按产品定义的站点导航状态恢复，不恢复编辑角色项目。

#### Scenario: 打开并关闭作品详情
- **WHEN** 用户设置多个筛选、滚动到作品并打开其详情，然后关闭
- **THEN** 原筛选和滚动位置保持，焦点回到打开详情的作品卡

#### Scenario: 浏览器返回离开详情
- **WHEN** 用户从画廊进入详情并触发浏览器返回
- **THEN** 关闭详情并回到之前的画廊状态，而非打开工作台或清除筛选

### Requirement: 全站弹窗必须由单一活动 overlay 协调
随机揭晓、作品详情和参考图创作 SHALL 使用同一活动 overlay。开启新内容时 MUST 替换当前 overlay 或显式返回原 overlay，不得堆叠抢焦点弹窗。overlay 打开时 SHALL 管理页面滚动、焦点进入/圈定、Escape 关闭和焦点恢复；浏览器 Back MUST 先退出当前 overlay/回到上一 overlay 状态，只有无 overlay 时才导航离开当前页面。从随机结果打开详情再返回时，原 DrawResult 必须保持。

#### Scenario: 从随机结果查看详情并返回
- **WHEN** 用户在随机弹窗中打开结果详情并选择返回
- **THEN** 详情替换随机内容；返回时恢复同一随机结果与揭晓状态，不存在两个同时可操作的对话框

#### Scenario: 在详情中打开参考图入口
- **WHEN** 用户从作品详情打开参考图创作，再关闭参考图弹窗
- **THEN** 返回原作品详情和焦点位置，底层页面滚动保持锁定直到 overlay 完全关闭

#### Scenario: 键盘关闭 overlay
- **WHEN** overlay 获取焦点后用户按 Escape 或以键盘操作关闭
- **THEN** 仅活动 overlay 关闭，焦点恢复到触发控件且页面滚动恢复

#### Scenario: 浏览器 Back 先关闭 overlay
- **WHEN** 用户从画廊打开随机弹窗后按浏览器 Back
- **THEN** 先关闭弹窗并恢复画廊状态；再次 Back 才离开画廊路由

### Requirement: 新页面与筛选必须适配窄屏和平板
首页、画廊、灵感游戏、随机 overlay、作品详情和参考图入口 SHALL 在桌面与 320px、390px、768px CSS 视口保持可读与可操作。触控和键盘可访问所有条件及主要操作；窄屏 overlay 可全屏呈现，MUST NOT 有遮断主要内容的横向溢出。

#### Scenario: 使用移动窄屏搜索和筛选
- **WHEN** 用户在 320px 或 390px 视口筛选画廊并打开详情
- **THEN** 查询、清除、结果卡和关闭操作可触达，详情关闭后恢复焦点和滚动

#### Scenario: 在 768px 游戏视口揭晓作品
- **WHEN** 用户在 768px 视口打开灵感游戏并查看结果
- **THEN** 卡片、进度、跳过和详情操作布局完整可用，无关键内容被遮挡
