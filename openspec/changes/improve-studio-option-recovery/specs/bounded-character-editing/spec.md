# Spec Delta

## ADDED Requirements

### Requirement: 组合限制必须区分素材缺口并给出具体恢复路径
编辑器 SHALL 将明确登记为尚无组合素材的限制与其它真实不兼容原因区分显示，同时提供跨分类的当前选择摘要。对于可通过调整其它字段到达的已登记组合，SHALL 指明字段、值和逐项可执行的顺序，优先恢复默认值；默认恢复无路径时可建议其它已登记值。每一步及目标组合 SHALL 合法；MUST NOT 自动修改其它选择或把缺失组合视为已支持。

#### Scenario: 单项组合素材没有交叉版本
- **WHEN** 用户已选择哈士奇的蓬松外观并查看针织背心
- **THEN** 背心保留不可应用状态，原因明确为组合素材尚未制作，并指明先将外观恢复为经典坐姿；恢复必须由用户显式选择，当前预览和 Prompt 不变

#### Scenario: 真实冲突或找不到已登记恢复目标
- **WHEN** 模板拒绝一个有实际遮挡或身份冲突的选项，且不存在逐项合法的已登记恢复路径
- **THEN** 界面保留登记的不兼容原因，不凭借未登记笛卡尔积建议可用组合，也不改变已有选择

#### Scenario: 默认耳机与云朵外观不兼容
- **WHEN** 用户在默认耳机角色中查看云朵外观
- **THEN** 云朵卡片简短提示先调整配饰，下方明确指引先选择无配饰；用户手动移除耳机后可以选择已登记的云朵组合

#### Scenario: 小卡片中的组合限制提示
- **WHEN** 用户查看暂不可应用的外观或其它选项
- **THEN** 小卡片只显示简短的待调整分类提示，卡片下方的整行说明区分素材缺口与真实不兼容并列出具体恢复字段、值及顺序；完整登记原因继续可读取，不用长段落撑高选项卡片，也不自动修改当前选择

### Requirement: 缩略图资源失败必须独立于组合能力
编辑器 SHALL 分别记录缩略图的等待、加载、成功、失败状态和组合兼容性。临时缩略图失败 MUST NOT 单独禁用合法选择或显示模板不支持；SHALL 保留选项文字和该项独立重试入口。主预览仍独立校验配方，未成功的最新结果不得导出。

#### Scenario: 单项缩略图网络失败后重试
- **WHEN** 一个合法选项缩略图返回临时网络错误
- **THEN** 该选项显示图片加载失败和文字，仍能选择；重试只恢复该缩略图，不改变 Draft、session、revision 或重新渲染成功主预览

#### Scenario: 失败选项同时存在组合限制
- **WHEN** 某项缩略图失败且它与当前选择不兼容
- **THEN** 界面同时保留素材失败和具体组合限制，重试成功不会解锁不合法组合

### Requirement: 缩略图加载必须让位于当前角色预览
系统 SHALL 在主预览完成后按当前可见分类加载可选缩略图，不预取未打开分类。切换分类或开始新预览时 SHALL 停止不再需要的缩略图工作；恢复加载不得把取消误记为失败，也不得覆盖新一轮结果。

#### Scenario: 首次打开和切换分类
- **WHEN** 用户打开角色并从外观切换到五官
- **THEN** 默认预览优先完成；首次只请求可见外观缩略图，切换后才请求五官缩略图，已成功缩略图可复用

#### Scenario: 弱网下连续选择和关闭
- **WHEN** 用户在慢请求完成前连续切换选项、分类或关闭面板
- **THEN** 上一成功预览保留并标记更新中，旧请求不得覆盖最新配置或新会话；只有最新成功预览对应的 Prompt 与透明 PNG 可用
