# Proposal

## Why

群内反馈暴露了角色组合限制与网络加载失败混用文案的问题；语言按钮显示目标语言也容易被理解为当前语言。已有合法配方和素材保持不变，先改善选择、恢复与加载体验。

## What Changes

- 全站语言使用可访问下拉框显示当前语言，切换保留作品、草稿、额外要求与当前分类。
- 区分未制作的组合、实际不兼容和资源加载失败；显示已选摘要及需要手动恢复的具体字段，不自动丢弃任何选择。
- 缩略图失败仅影响图片展示，保留文字与合法选项可操作性，并提供单项重试。
- 当前可见分类按需加载缩略图；主预览优先，隐藏分类或被新预览抢占的缩略图请求可取消并延后重启。
- 验证弱网、连续选择及语言切换下预览、Prompt、导出的一致性和失败恢复。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `bounded-character-editing`: 独立的组合限制、缩略图状态及按需加载恢复合同。
- `studio-visual-experience`: 当前语言下拉框及无损切换合同。

## Impact

涉及 `dist/studio.js`、`dist/index.html`、样式、编辑器与相应回归脚本。不增加依赖，不更改原图、模板配方或批准记录；不发布生产站点、不合并 PR，不归档 change。

## Non-goals

不新增角色、补齐缺失组合、改变素材层结构或制作新缩略图素材。本轮先通过请求调度减少非必要加载，独立小缩略图管线留待单独变更。不承诺任意组合，也不添加全局 Reset/Cancel。
