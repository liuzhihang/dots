# Design

## Context

基线 main 4991ab8。44 个模板的 540 条配方已有批准，部分模板的 non-default 组合只有单项版本。现有 preview token、revision gate 与旧画布保留机制正确；问题主要是控件缩略图失败调用能力禁用函数、全分类同时加载，以及语言按钮语义。

## Goals / Non-Goals

**Goals:** 在不动素材与配方的条件下改善明确性、失败恢复和请求优先级；用故障注入证明状态分离。

**Non-Goals:** 不生成新素材、不增加合法组合、不制作派生缩略图管线、不改批准状态或发布。

## Decisions

1. 使用原生 select 显示当前语言，沿用已存在的 detail.setLanguage 原地更新；不新增自定义弹层焦点管理。
2. 从现有 conflict code 的 separate-fit 和 unregistered-recipe 分类为素材缺口，其它原因保留原文。恢复提示优先广度优先搜索其它字段逐项恢复默认的合法路径；没有默认恢复路径时，在已有合法配置中搜索逐项调整路径。每一步仅改变一个其它字段，验证每个中间状态和目标完整配方，不自动应用、不新增全局 Reset。选项卡片仅显示简短分类提示，具体字段、值和顺序放在整行说明中，完整登记原因仍可读取。
3. 缩略图错误使用独立状态和每项重试按钮。缺少注册资源仍为真正不可用；503/解码等缩略图失败只显示占位，不污染兼容性。重试独立于主预览重试。
4. 控制器绑定各选项，切换分类取消隐藏项；新预览开始取消可选缩略图，在最新成功预览后仅加载可见项。成功图不销毁，取消回到等待状态；generation 防旧回调覆盖。
5. 继续使用已验证源到无损 WebP 的 loader 缓存及引用计数，不重做缓存、不把刷新或请求记录误认为重复下载。

## Risks / Trade-offs

- [缩略图仍使用完整图层] → 本轮只削减请求数量与竞争，不承诺单张字节量降低；避免牵动素材清单和批准链。
- [通用 code 推断错误] → 只识别明确 separate-fit / unregistered-recipe，其它保留登记原因；不修改验证器合法性。
- [取消最后消费者导致再次 fetch] → 已完成缓存保留；只取消不再需要的选项请求，并回归主预览共享 lease 不受影响。
- [恢复建议改变用户选择] → 仅文字提示和已有字段导航，用户逐项手动选择。

## Migration Plan

保持 change 未归档；无需数据迁移。2026-10-13 用户已授权本地验收全部通过后合并 PR #4，并按发布清单发布到现有 dots Sites 项目，随后完成线上交互与 PNG 复验。回退该 PR 即恢复旧控件与调度，素材身份不受影响。

## Modal language access correction

全局 select 位于 pageShell 时会被 showModal 与 inert 排除出编辑面板的交互范围。修复采用同一 DOM 控件搬移：overlay 在锁定背景前将其移入标题栏挂载点；关闭、原生 close、打开失败和 destroy 恢复原父节点与相邻位置。状态处理器仍唯一，不添加独立详情语言偏好。标题栏显式四列和固定行，覆盖原三列规则，手机允许标题换行。

真实浏览器验收必须用用户可执行的点击、Tab 与键盘选择，不得使用 DOM 赋值/dispatchEvent 绕过模态可访问性；检查四项标题栏控件同行、不重叠和不溢出。

## Local acceptance corrections, 2026-10-13

原生语言与排序 select 使用统一箭头、对称内边距、44px 高度和单一键盘焦点框。小屏语言控件固定宽度，标题可换行但不得重叠。

按用户追加要求，关闭按钮、返回、Esc、图库导航、浏览器返回至图库和页面离开均不显示确认框，关闭后重开恢复默认配置；切换其它作品或版本继续使用既有草稿确认。自动化对直接关闭的断言同步调整。
