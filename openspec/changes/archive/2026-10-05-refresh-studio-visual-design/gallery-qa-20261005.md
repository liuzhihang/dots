# 家族群像、内置形象与工作台页面核对 · 2026-10-05

## 本轮交付范围

按用户要求将封面、内置形象和工作台分开：首页使用 12 张不同的独立角色 PNG，五张家族卡各呈现本组 3 位成员；内置形象是一个可筛选、搜索的完整画廊，共 15 项；工作台移除 Artwork / Composer 模式页签。封面家族卡进入对应画廊，每个角色只有一个“用这个形象定制”入口。

每组保留既有一只 canonical 基准，另两只是本轮有限的展示候选。15 是本 change 的实现规划，并非用户指定数字。所有角色均保留待用户真实网页美术确认状态；本轮没有认定任何基准或家族美术通过，也不开放继续无限扩充。

人物、动物是重新设计的原创角色；Dots、Grok Bot、Meta Muse 根据允许的身份参考独立再创作，标记非官方。素材来源、SHA、识别特征、配饰承托及禁止项见 [gallery-looks-20261005](references/gallery-looks-20261005/README.md)。本轮另将七张已无运行时引用的错误 Grok/Muse 历史 WebP 原样移到非发布参考目录，SHA 与基线一致，见 [retired-assets](references/retired-assets/README.md)。

## 实际预览环境

CUA IAB 载入本机 `http://127.0.0.1:59811/`，服务器直接只读提供当前 `dist/`。主要截图阶段入口和模块为 `?v=61`；最后窄修统一到 `?v=62`，再次实际 reload 核对所有样式/主模块版本、12 张主视觉载入、Dots 配方 Canvas 与 error/warn 空结果。窄修没有改变截图中的页面布局。Vite 本机预览对静态文件返回长期 immutable 缓存，先前同 URL 样式未及时刷新；因此最终页面核对使用上述静态预览，而没有修改框架或依赖。

视口分别为 1280×900、768×1024、390×844、320×740。document 可用宽度扣除 15 px 滚动条，分别为 1265、753、375、305 px。截图只保存实际布局稳定后的视口画面；变更视口瞬间的旧尺寸裁切截图不作为证据。
