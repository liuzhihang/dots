# Acceptance Matrix

这是待执行的验收合同，不是本轮测试报告。所有性能数值为本次建议的实验目标，不是已测成绩或所有设备的承诺。

## 环境记录

记录source/HEAD/dirty摘要、实际deploy build、浏览器/版本、viewport CSS尺寸、DPR、设备/CPU/内存、网络限速与缓存状态、资源版本/总字节。无法访问线上时用匹配构建本地验证并明确边界，不以旧提交或图片镜像冒充现站。
视口：1440×900、390×844，320与768px边界。EN、zh-CN；普通动态与reduce。

## 性能实验

分别记录：click → panel-mounted → metadata/actions-ready → preview-visible → detail-preview-ready → edit-ready。
在约定参考浏览器/设备、壳与目录已加载时，panel-mounted目标≤100ms，>200ms列为阻塞问题。此阈值不是现场INP指标。
冷资源慢网情况下，面板/元数据仍不等待原图；高清阶段单独显示状态。每种缓存情况至少5次记录全部样本与中位数，少样本p95标明仅为实验描述。
主图/模板实际请求要区分：不在普通View首开加载全部配件/全原图池/相关推荐；复开同版本不得出现不必要的完整重复处理。
连续开关/改角色20次，检查遗留请求、Blob URL、bitmap/内存是否持续增长；结束时不应有未释放消费者及迟到回调改变UI。
不要用预载所有内容换好看的热缓存数字；同时报告首次负载、网络数据量和CPU解码/合成长任务。

## 有限组合验证

至少列出一套Dots和一套Grok代表模板的合法集合、非法规则和资源能力。对首批有限合法集合执行配置/资源/渲染/alpha自动检查；逐项核对有限公开配件和关键交叉组合的接触/遮挡/材质。
整张图美术符合度不等于模板已验证：必须真的执行颜色、眼睛或配饰改动、再下载打开新文件。
全站全部降级view-only/Prompt-only不能将bounded-editing验收标完成。
