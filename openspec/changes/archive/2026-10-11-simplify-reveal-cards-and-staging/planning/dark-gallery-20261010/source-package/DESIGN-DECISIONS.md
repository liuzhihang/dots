# 设计决策与原型裁决

## 1. 主辅稿

| 范围 | 依据 | 明确限制 |
|---|---|---|
| 角色库首页 | D01左侧01 | 首页与画廊是同一产品入口，不再多一张宣传首页 |
| 角色查看 | D01中间02 | 只是统一面板的View状态，不是独立实现 |
| 角色编辑 | D01右侧03 | 同一尺寸/同一角色预览区域切换，不另开工作台 |

| 角色身份 | C01–C03与仓库已批准母版 | 原型错画不替代身份母版；其他系列读取仓库实际资源 |

## 2. 必须纠正图中的误生元素

- 删除庭院、教室、台阶、远景城市、花园、木桌、景观灯和大量布景；顶部品牌群像也不得藏着一个小房间。
- 删除宇宙背景、大面积星空、光环、发光基座、镜面地板、每张卡外发光与彩虹流程线；弱蓝紫明暗仅用于空间层次。
- 删除`100+`、`6 Collections`、无限符号式统计、Popular排行、虚假授权、固定文件尺寸、假动画数量及占位“更多角色”产品卡。
- 删除登录、头像、个人空间、收藏/心形按钮、社区、社交计数、宣传视频入口和随机抽卡。
- 导航仅`Characters / Guide / EN or 中文`；品牌回到角色库。不同时出现Home、Gallery、Characters、Explore四个同义入口。
- 桌面正文和控件使用同一个当前语言；不要照抄拼版上混排的中英文字或错别字。
- Grok是软几何与成对胶囊眼，不是屏幕脸机器人；机器人作为独立原创类别/标签登记，不冒充Grok。
- Muse使用C01包覆轮廓与内嵌脸面，不是耳朵下垂的长毛云团；Dots使用细密短绒，不外扩成长毛轮廓。
- Dots/Grok无肢体基准不新增手脚；Muse、人物、动物按各自母版保留合理肢体。
- 不新增黑影椭圆团或发光地面到透明成品里；预览底色不进入透明导出。
- 源图、变体、实际动画、局部编辑与Prompt意图分开：不能用不同角色充当同一角色动作，也不能宣称未适配编辑结果自动拥有动作包。

## 3. 页面与容器

### 角色库首页

- 深石墨连续画布，角色本身是主要色彩；不要把每个角色关进明显的玻璃方盒。
- 上方只保留短介绍，默认标题`Make It Your Dot.`，说明`Pick a character. Copy a prompt. Make it yours.`。
- 主操作`Copy Dots Prompt`，次操作`Browse characters ↓`滚到同页角色网格；复制成功反馈后给出到ChatGPT附图的说明。
- 品牌群像为可选小型元素，Dots占主，但不代表只展示Dots；正式网格必须保留Dots、Grok Bot、Meta Muse、人物、动物。
- 以1440×900 CSS viewport评审，导航约64px；简介区域建议180–240px，首屏露出一整排真实作品。最终尺寸在设计文档中记录，不照抄压缩拼版尺寸。
- 搜索与系列筛选就近；All / Dots / Grok Bot / Meta Muse / People / Animals。
- 默认5–6列，768px约3列，390px两列，320px仍可用；不为凑列数裁帽子、耳朵、头发、脚或尾巴。
- 每项只保留完整图、短名称、系列；仅对真的有编辑模板者显示轻量Editable标记，不加虚构状态。
- 当前语言大小写、名称和分类在首页、详情、Prompt中一致。
- 排序只用真实字段支持的精选/最新/名称；无数据不显示热度排行。

### CharacterStudio：View与Edit

- 同一组件、同一作品身份、同一面板壳与预览区域；右側从信息切换为编辑控件。
- 桌面一个大浮窗，移动端一个全屏面板；直接访问角色URL时使用同一组件的独立宿主，不嵌套弹窗。
- View：完整预览、标题、短描述、最多4个精选标签、Copy Prompt、Download original、Open in ChatGPT、Prompt摘要、实际已有变体/动作。
- View不能等待模板、全部配件、相关推荐或原图SHA才出现；先复用当前封面和元数据。
- Edit：Color / Shape / Eyes / Glasses / Accessories；控件按模板实际能力显示，不强迫每个系列拥有相同Tab。
- 默认原配置；选择后产生内存草稿，预览真实变化。View显示原作品；切回Edit保留本次内存草稿，界面明确Original/Draft，不悄悄覆盖。
- 取消/重置回到当前基准；有改动关闭时提供继续编辑/放弃确认。不要为了保留草稿接数据库或读取旧存储。
- 导出当前PNG与下载原图是不同操作。导出按钮只在最新选项已渲染成功后启用。
- 预览背景深/浅/棋盘格只是检查透明度，不改输出背景；本期不加独立背景创作Tab。
- 为真实已支持的模板提供本地编辑；只提供ChatGPT编辑的作品明确提示，不能将静态原图伪称实时预览。

### Guide

按“挑选/复制 → 在ChatGPT附参考图创作 → 按实际目标要求使用”的简短路径。
本站不自动附图、不保证自动安装，现有动作与Pet目标包只有真实验证才可显示。

## 4. 视觉tokens（本次起点，形成页面级稿后锁定）

- bg `#0B0D12`
- surface `#141821`
- elevated `#1C2230`
- text `#F4F6FB`
- muted `#A9B1C3`
- accent `#7C3AED`
- border：白色低透明度，禁止每个边框霓虹；交互focus需明显可辨。
- 深色与英文为首发呈现，同时实现zh-CN。角色图片不加全局紫色滤镜。
- 局部玻璃用于导航、搜索、浮层外壳；正文、Prompt、编辑控件用稳定实色表面。
- 无背景复杂度时不强上backdrop blur；不透明化整个父容器使文字一同变淡。
- 控件可点击尺寸、对比度与focus可读性在真实页面检查，不能仅凭色表声明通过。

## 5. 动态

先静态封面，真实动画按需加载。Hover或focus的短回应不影响点击热区。
无实际帧资源时只做明确的UI反馈，不叫眨眼/挥手。
离屏暂停；打开Studio后暂停背景图库；reduce模式静态但保留完整操作。
首版不要求所有角色做动画；有资源才显示播放按钮。
