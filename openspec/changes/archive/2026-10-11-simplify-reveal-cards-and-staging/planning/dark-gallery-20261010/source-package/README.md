## 一句话范围

角色库就是首页；点击进入同一个 CharacterStudio，默认 View，按实际能力切换 Edit。全站采用深石墨数字画布与局部烟黑玻璃，不再使用庭院、城市、台阶或独立工作台。

## 文件怎么使用

1. 将整个包附给已经打开 `liuzhihang/dots` 本地工作树的 Codex 会话。
2. 首先发送 `CODEX-CHANGE.md` 的内容。它要求优先修订本地相关未归档 change；没有才创建上述新 change。
3. `change-source/` 是规划输入，不是可直接覆盖本地 OpenSpec 的安装包。Codex 必须读取真实本地主规范与 schema，再生成正确 ADDED/MODIFIED/REMOVED deltas，并运行已安装版本的校验。
4. 规划与素材缺口确认后，再发送 `CODEX-APPLY.md`，进入实现与验证；不自动提交、推送、部署、sync 或归档。
5. 未单独附上整个历史聊天也可以工作：本包包含本轮边界；聊天只补充历史，不高于本轮明确决策。

## 原型优先级

- **D01（最新第3张）为唯一主稿**：首页角色网格、View/Edit 信息架构、深色层级。
- **D02（最新第1张）为辅助**：移动端与指南的简洁表达。
- `DESIGN-DECISIONS.md` 中的明确纠偏高于图中矛盾或误生的元素。
- C01–C03 是用户给定的身份/材质参考，不是新的页面方案，也不证明品牌授权或平台官方标准。
- 这次的第1/第3张与更早“第三张＋最后一张阶梯露台”的选稿无关，不能混用编号。

本包图片保持原字节，未重画或修图；主辅稿里仍有需按文字纠正的示例。拼版不是原生1440px页面，不应按面板缩放尺寸直接开发。

## 与旧交接的变化

- 取代“完整阶梯露台/庭院为首页”的设计决策。
- 取代“任何运行时编辑都禁止”的旧产品规则：现在允许明确模板内、受控、真实的浏览器编辑。
- 不取代历史批准记录、素材来源、原图、Git历史、已归档spec或验收证据。
- 无用户上传、无数据库、无账号、无站内模型调用、无旧版兼容保持不变。
