# Dot Icon Studio 产品与设计约定

用户路径：挑选完整角色 → 共用详情 → 复制 Prompt / 下载已有作品 → 在 ChatGPT 自行附图创作。范围为单场景首页、开放画廊、共用详情与轻量指南，英文默认及简体中文。详情内折叠的修改区只生成文字，不改变图、标签、原始 Prompt 或下载。

## 原型与页面

当前 change 的 planning/static-experience-20261009/references/P02-selected-last.png 决定首页宽幅、阶梯纵深、群组和留白；P01-selected-third.png 决定画廊、详情、移动端层级、控件与克制黄昏色。拼版不是页面尺寸稿，不裁取其中像素生产资源。首页只有一个露台：1440×900 下导航约64px、Hero约520–580px，前中远景留空台阶，不使用100vh。近处2–3只互动、中间3–4只合作、少数安静独处；远景伙伴较小但清楚。

场景拆成无角色环境、必要家具/遮挡、角色或局部互动单位、固定语义按钮。hover/focus只给短回应；点击/Enter/Space/手机单次轻点立即打开同一详情，不等动画，不自动开浮窗，热区不跟随动画移动。无真实动画则静态，不虚构变表情。

画廊浅色开放网格、完整contain、光学尺寸平衡，弱化卡片边界，不做每角色小场景/底座。一个文本搜索和单系列筛选，多词AND、系列与文本AND。默认静态poster按视口加载，不预取全部原图。

## 内容与身份

保留15个既有Artwork ID/version、原图字节和v83批准引用。Character身份、Artwork成品、Asset用途、ScenePlacement、Prompt意图分离。真实动作/变体只显式登记，当前没有则隐藏。八类事实保留none/notApplicable/unknown差异。

Dots短密绒和清楚轮廓，无肢体基准不得长手脚；Grok Bot软几何胶囊眼不是屏幕脸；Muse按C01奶油包覆体/内嵌脸/短圆肢体；柴犬立耳橙白口鼻四足卷尾；人类皮肤/发丝/衣料保持区别。统一光照，不统一成毛绒。

## 详情与边界

首页/画廊/直链共用一份详情，绑定同一ID/version。桌面浮窗、窄屏全屏；返回恢复来源、搜索、筛选、滚动与焦点。原图失败不阻塞文字。只显示真实文件和精选事实，不展示未验证许可/尺寸/格式/Pet能力。下载原始字节，不Canvas重绘。修改意图区分保留/移除/替换，空值不是移除；不向人物、动物或Muse套Dots换形。折叠/语言切换保留草稿，关闭/成功变体切换清空。

不做上传、存储库、API/CMS、账号/收藏、社区、模型调用、通用配件、游戏、第二场景或旧兼容层。保留浏览器/响应式/减少动态和失败降级。旧运行退出dist，来源/批准/历史保留。实施工程验证不代表用户批准新素材或页面。
