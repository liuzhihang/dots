# Dot Icon Studio 产品与设计约定

用户路径：挑选完整角色 → 共用详情 → 复制 Prompt / 下载已有作品 → 在 ChatGPT 自行附图创作。范围为单场景首页、开放画廊、共用详情与轻量指南，英文默认及简体中文。详情内折叠的修改区只生成文字，不改变图、标签、原始 Prompt 或下载。

## 原型与页面

P01 与 P02 都是多页概念拼版，必须分别识别首页、画廊、详情和手机面板，不把整张拼版当单页或生产素材。P02 对应桌面首页的宽幅比例、台阶纵深、前中后景和留白；P01 对应画廊、详情、手机层级与控件，并提供首页克制黄昏光色。首页只有一个黄昏露台：1440×900 下导航约64px、Hero内容约560px，首屏主体约624px，不使用100vh。近处互动、中景合作/阅读、远景伙伴与空台阶之间保留疏密和通道。

每个视口使用一张完整合成的静态场景图，图内统一人物、动物、家具、台阶、承托、接触阴影和遮挡关系；不叠透明角色群组或家具层。v97 桌面候选为1942×809，现有15个Artwork身份均各出现一次，场景表的15个热点分别绑定对应ID/version。600px及以下使用同一露台的专用手机竖幅图，热点仅对应手机图实际可见者；大于600px使用桌面图，平板cover裁切只保留仍完整处于可见图像内的热点。场景图和最终页面仍待用户艺术确认，15张原图的历史批准不扩大到整景。

hover/focus只给短提示；点击/Enter/Space/手机单次轻点立即打开同一详情，不等动画，不自动开浮窗。热区固定对齐当前视口完整场景图中的真实角色，不能随图像动作移动。首页整景保持静态，不声称单角色独立表情动画；无真实动画则不显示播放控件。

画廊浅色开放网格、完整contain、光学尺寸平衡，弱化卡片边界，不做每角色小场景/底座。一个文本搜索和单系列筛选，多词AND、系列与文本AND。默认静态poster按视口加载，不预取全部原图。

## 内容与身份

保留15个既有Artwork ID/version、原图字节和v83批准引用。Character身份、Artwork成品、Asset用途、完整SceneArt、只含热点坐标的ScenePlacement、Prompt意图分离。真实动作/变体只显式登记，当前没有则隐藏。八类事实保留none/notApplicable/unknown差异。

Dots短密绒和清楚轮廓，无肢体基准不得长手脚；Grok Bot软几何胶囊眼不是屏幕脸；Muse按C01奶油包覆体/内嵌脸/短圆肢体；柴犬立耳橙白口鼻四足卷尾；人类皮肤/发丝/衣料保持区别。统一光照，不统一成毛绒。

## 详情与边界

首页/画廊/直链共用一份详情，绑定同一ID/version。桌面浮窗、窄屏全屏；返回恢复来源、搜索、筛选、滚动与焦点。原图失败不阻塞文字。只显示真实文件和精选事实，不展示未验证许可/尺寸/格式/Pet能力。下载原始字节，不Canvas重绘。修改意图区分保留/移除/替换，空值不是移除；不向人物、动物或Muse套Dots换形。折叠/语言切换保留草稿，关闭/成功变体切换清空。

不做上传、存储库、API/CMS、账号/收藏、社区、模型调用、通用配件、游戏、第二场景或旧兼容层。v96因原型差距大、角色悬浮且与背景无关、角色缺少、把多页拼版误当单页而被用户拒绝；其证据保留为历史，v97整景与页面继续等待用户确认。保留浏览器/响应式/减少动态和失败降级。旧运行退出dist，来源/批准/历史保留。工程验证不代表用户批准新素材或页面。
