# v69 过程矩阵

v69 是角色接触与渲染修复前的过程检查快照，不是最终角色版本，也不是网页美术验收通过记录。它包含五个家族各自的 WebGL 与 software/CPU 实际下载矩阵：共 10 份、3,798 条记录。Dots、Grok Bot、Meta Muse、人物各为每条渲染路径 378 条；动物每条路径 387 条。原始下载文件名、SHA-256、字节数、矩阵状态和 source snapshot 对应关系见 [`frames/raw-source-index.json`](frames/raw-source-index.json)；按用例提取的帧和矩阵文件见 [`frames`](frames/)。

这些矩阵均记录为 `section=all`、`status=recorded`，且 `userArtApproved=false`。完整采集、成功提取、边界指标或两个渲染器均有记录，只能证明此快照的取样范围，不证明成品质量、网页视觉验收、用户认可或发布通过。源版本的冻结清单见 [`source-snapshot.json`](source-snapshot.json)。

## 已知缺陷

- Dots 的 bucket 配饰缺少网格，配饰结构尚未完成。
- Meta Muse 的镜腿埋入头罩，配饰接触关系不正确。
- camera 挡住角色脸部下半部，身份特征受到遮挡。

这些缺陷在 v69 中仍然存在。Meta Muse 的边界帧清单只是构图边界的诊断记录；触边或画面裁切指标本身不代替对角色是否完整、可辨识的人工判断。

## 后续验收门槛

等待 v70 修复后，必须针对更新并重新冻结的同一源版本重新采集、提取和核对完整五组双渲染矩阵；检查 bucket 网格与配饰接触、Muse 镜腿/头罩关系、脸部无遮挡、主体身份与材质，以及动作和导出帧。随后仍须在真实网页中逐组进行视觉验收并由用户确认。不得将 v69 作为修复后的证据，也不得仅凭矩阵数量、PNG、构建结果或任务勾选宣称通过。

人物和动物的资产仍必须原创设计；动漫截图不得用作运行素材、贴图或可识别的完整角色复刻。此矩阵不改变这一素材边界，也不构成来源许可判断。
