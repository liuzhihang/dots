# Spec Delta

## Purpose

定义角色图库如何分别展示普通静态图、动作变体、可播放动画与目标平台资源，按官方资料、端和版本记录格式及验证边界，避免将风格相似或单张透明图片等同于可安装 Dot/Pet，并支持未来独立资源扩充。

## ADDED Requirements

### Requirement: 资源类型与动态能力必须如实区分
系统 SHALL 区分透明角色静态图、完整静态动作/表情、实际动画预览、sprite sheet、目标包及场景插画。静态动作、动作拼贴、页面卡片滚动或 Prompt MUST NOT 标为可播放角色动画。没有实际动画文件时只展示静态/创作 Prompt 能力。

#### Scenario: 作品包含眨眼单帧或动作拼贴
- **WHEN** 用户查看一张眨眼 PNG 或静态 WebP 动作展板
- **THEN** 页面说明其单帧/示意性质，不提供不存在的循环播放或动画包下载

### Requirement: 目标格式资料必须记录来源端版本与验证状态
目标资料 SHALL 记录平台、端、版本、文件格式、尺寸、alpha、帧布局、状态/动作、制作方式、来源链接、查询时间和验证状态。官方文档、本地工具合同与实际目标环境验证 SHALL 分开；来源未说明的布局或端能力保持待验证。资料变化不得自动改变作品资源或扩大支持标识。

#### Scenario: Web官方说明只有文件尺寸而本机合同另有帧表
- **WHEN** 页面展示 Web Pet 格式资料和本机 v2 sprite 合同
- **THEN** 两者明确来源及适用范围，未证实的 Web 帧布局/跨端支持标记待验证，不把本机合同当成全部端官方要求

### Requirement: 普通PNG不得标为已验证的Dot或Pet安装包
普通静态角色 SHALL 可以按其真实资源正常下载，但 MUST NOT 因透明、风格相似或带目标 Prompt 而显示可直接安装、目标已验证或通用 Dot/Pet 支持。Dot 文档允许选择角色/Pet不构成任意 PNG 导入授权；目标环境未测试时明确待验证。

#### Scenario: 下载蓝色Dots静态PNG
- **WHEN** 用户查看或下载普通完整角色图
- **THEN** 标识为静态透明 PNG，与目标说明和创作 Prompt 分开，不显示已验证 Dot/Pet 安装能力

### Requirement: 本期不得制作或开放未经授权的目标包
本期 SHALL 交付静态图库及目标资料，不制作 Pet sprite sheet 或安装包，不因规划有扩展位就启用包导出/安装按钮。后续开放目标资源 SHALL 另有明确范围、实际文件及端/版本验证证据，不能用未来任务或占位 URL 当现有资源。

#### Scenario: 首期目录没有目标包
- **WHEN** 用户打开作品详情的目标用途说明
- **THEN** 页面提供已核实资料与待验证状态，Pet 包导出和安装按钮不存在，静态图下载仍可使用

### Requirement: 页面底色作品背景与目标alpha必须分开
页面、卡片和弹窗 SHALL 能使用设计底色而不写入角色文件；默认抽取/导出 SHALL 使用真实透明角色资源且无独立脚底阴影团。场景插画 SHALL 作为不同资源类型和背景事实登记，不混入默认透明角色池或冒充目标透明资源。

#### Scenario: 在浅色卡片或深色随机弹窗中下载
- **WHEN** 用户从带设计底色的视图下载角色原图
- **THEN** 下载仍是该作品的透明文件，尺寸/hash/画面对应登记资源，不包含 UI 底色或新增脚底阴影团

#### Scenario: 展示一般场景插画
- **WHEN** 后续登记一张有环境背景的插画
- **THEN** 其背景和资源类型如实标明，默认角色随机/导出不将其当透明角色或可安装 Pet
