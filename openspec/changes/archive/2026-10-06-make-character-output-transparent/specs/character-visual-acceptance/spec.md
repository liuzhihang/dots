# Spec Delta

## MODIFIED Requirements

### Requirement: 美术验收必须检查真实页面和实际受支持合成
验收 MUST 在可访问的真实图库、工作台和首页中查看实际模板、已登记组合素材及 Canvas，并检查角色真实透明 alpha。背景字段不是受支持的合成能力；不得要求用户选择背景来证明输出，实际预览、模块组合和 PNG 只按透明结果检查。组合图鉴、独立生成图、缩略图、构建成功与任务勾选不得单独作为网页美术证据。独立组合素材 MUST 按其声明的基底、姿态和接触关系检查；未支持的自由视角、比例、配饰或材质 SHALL 只进入 Prompt，并明确不改变当前 PNG。首页现有搜索、`homeFamilies` 五组场景、布局、群像、卡片、导航和文案 MUST 保持现有设计；首页家族插画与页面底色不随角色输出透明化而改变。标签浏览控件只出现在图库和工作台，现有首页卡片可通过内部路由携带图库标签筛选条件而不改变首页呈现。项目菜单 MUST 移除旧角色 JSON 导出项 `save-character` 并保留统一 v2 项目导出、菜单容器和其他功能。浏览器回归 MUST 核对首页视觉及现有全局随机入口可用；移除背景功能入口和旧导出项记录为预期功能差异。

#### Scenario: 检查真实工作台
- **WHEN** 验收人员查看登记模板、组件配方或 PNG 导出
- **THEN** 当前 Canvas 和 PNG 使用真实透明 alpha，记录页面来源、版本、模板与配置；未支持高级设置不伪称已渲染，首页艺术底色保持实施前设计

#### Scenario: 只有生成图或构建记录
- **WHEN** 没有真实页面观察和明确用户确认
- **THEN** 对应美术确认保持未执行，不能因图像精细、构建或任务完成记为通过

#### Scenario: 检查新组合素材的真实接触关系
- **WHEN** 验收人员在真实工作台检查一个声明支持的模块化素材配方
- **THEN** 页面证据绑定素材、基底、姿态、视角和版本，记录实际遮挡/接触及未检查范围；内部图鉴状态仍与用户确认状态分开

### Requirement: PNG下载与Prompt回读结论必须对应实际产物
声称某 PNG 或 Prompt 输出已验证时 MUST 回读真实结果：原始 PNG 记录实际文件、画面、尺寸、alpha 和哈希；Canvas PNG 另记录对应合成配置及实际画布尺寸、透明通道、画面和哈希；Prompt 记录实际剪贴板或文件文本。结构诊断 3D 与共享 2D 诊断 PNG 也 MUST 回读实际字节并检查 alpha。成功 toast、按钮可用、用户美术确认或单张抽样不能单独作为全量技术输出通过证据；有限目录声称全量通过时 MUST 明确覆盖全部适用 look、配方状态和透明输出。

#### Scenario: 检查一张实际下载PNG
- **WHEN** 验收者只核验一张当前模板 PNG
- **THEN** 记录该文件及配置和版本，不推断其他模板下载字节或全部透明边缘均通过

#### Scenario: 检查Prompt复制
- **WHEN** 页面复制 Prompt 后回读系统剪贴板
- **THEN** 只在内容与当次冻结 Prompt 一致时记录该次通过；没有回读时保持未验证

#### Scenario: 声称当前有限输出全量通过
- **WHEN** 验收者报告当前登记模板与模块配方输出全量通过
- **THEN** 证据逐项覆盖适用的 15 个 look、22 个模板状态及当前 5 个模块配方，回读原始 PNG 与 Canvas PNG 字节/画面/尺寸/alpha/SHA-256 以及对应 Prompt；无法执行项说明原因并保持未通过或未验证

#### Scenario: 首页视觉保持且全局随机入口可用
- **WHEN** 验收人员在固定浏览器和视口检查首页，并从现有入口打开全局随机弹窗
- **THEN** 首页布局、群像、卡片、导航、文案与艺术底色保持冻结基线；现有随机入口可以打开并显示透明角色结果，未接入真实素材的随机结果仍如实标记为未验证

#### Scenario: 标签浏览不增加首页控件
- **WHEN** 用户从现有首页卡片进入图库并使用标签筛选，或在工作台打开标签浏览
- **THEN** 首页展示与文案保持不变，标签筛选只改变图库结果范围，标签控件位于图库或工作台且不会覆盖活动作品

#### Scenario: 项目菜单仅移除旧格式导出入口
- **WHEN** 验收人员在工作台打开项目菜单并执行 project v2 导出
- **THEN** 旧 `save-character` 角色 JSON 导出项不存在，v2 项目导出、菜单容器和其他菜单功能仍可用；该差异记录为旧格式停用的预期行为

## ADDED Requirements

### Requirement: 捕获调用不能覆盖角色透明输出
任何角色 Canvas、组合图鉴或结构诊断的捕获调用 MUST 保持真实透明 alpha，不得将预览界面底色或显式要求的不透明底色写入 PNG。

#### Scenario: 捕获调用要求不透明底色
- **WHEN** Canvas、组合图鉴或结构诊断捕获请求 `transparent: false`
- **THEN** 实际 PNG 仍有真实透明 alpha，调用方不能把预览界面底色写入角色画面
