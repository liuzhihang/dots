# Spec Delta

## MODIFIED Requirements

### Requirement: 模板能力检查与人工美术确认必须分开
画廊原图、工作台 Canvas、Prompt、组合覆盖图鉴与旧结构诊断 SHALL 分别记录能力和证据。模板与新增组合素材的美术 MUST 在真实页面检查身份、材质与配饰接触并由用户确认；逻辑测试、构建、图鉴、图像差异或诊断矩阵不能代替该确认。用户美术确认 MUST 绑定实际冻结版本及可核定的 look/状态/素材映射，MUST NOT 自动证明全量 PNG 字节、剪贴板、实体手机或旧三维成品工程通过。Site version 35/cache 83 的确认记录明确列出15个 look 和“PNG模板、背景合成、Prompt”范围；其 `supportedStateBoundary` 表述为当时工作台提供的登记状态，但没有逐姿态 PNG 的素材映射。该记录对具体姿态文件的覆盖 SHALL 标记为“确认范围待核定”，MUST NOT 自动断言已逐图批准或被用户否决。

#### Scenario: 模板美术获得用户确认
- **WHEN** 用户明确确认具体页面版本中的已登记形象和范围
- **THEN** 只将该版本、清单内身份及明确范围记为已确认，工程输出或设备未检查项保持其实际状态

#### Scenario: 缺少支持当前配置的素材
- **WHEN** 配置没有可信模板或完整配方
- **THEN** Prompt/JSON可用，但当前PNG不允许导出；诊断图不能补足素材缺失

#### Scenario: 用户确认记录未逐项映射到姿态文件
- **WHEN** 历史确认记录列出15个Gallery look，并以“当前工作台所提供的登记状态”描述状态范围，但没有姿态 PNG 的逐文件映射
- **THEN** 15个已列 look 保留记录范围内的确认，姿态文件的用户确认显示“确认范围待核定”，不得自动标成已批准或用户否决

### Requirement: 美术验收必须检查真实页面和实际受支持合成
验收 MUST 在可访问的真实图库、工作台和首页中查看实际模板、已登记组合素材及 Canvas，对已声明支持的背景、完整配方或姿态进行检查。组合图鉴、独立生成图、缩略图、构建成功与任务勾选不得单独作为网页美术证据。独立组合素材 MUST 按其声明的基底、姿态和接触关系检查；未支持的自由视角、比例、配饰或材质 SHALL 只进入Prompt，并明确不改变当前PNG。首页现有搜索、`homeFamilies` 五组场景、布局、群像、卡片、导航和文案 MUST 保持现有设计；标签浏览控件只出现在图库和工作台，现有首页卡片可通过内部路由携带图库标签筛选条件而不改变首页呈现。项目菜单 MUST 移除旧角色 JSON 导出项 `save-character` 并保留统一 v2 项目导出、菜单容器和其他功能。浏览器回归 MUST 核对首页视觉及现有全局随机入口可用，并将旧导出项移除记录为预期功能差异。

#### Scenario: 检查真实工作台
- **WHEN** 验收人员查看登记模板并修改支持的背景或完整配方
- **THEN** 当前Canvas按受支持设置合成，记录页面来源、版本、模板与配置；未支持高级设置不伪称已渲染

#### Scenario: 只有生成图或构建记录
- **WHEN** 没有真实页面观察和明确用户确认
- **THEN** 对应美术确认保持未执行，不能因图像精细、构建或任务完成记为通过

#### Scenario: 检查新组合素材的真实接触关系
- **WHEN** 验收人员在真实工作台检查一个声明支持的模块化素材配方
- **THEN** 页面证据绑定素材、基底、姿态、视角和版本，记录实际遮挡/接触及未检查范围；内部图鉴状态仍与用户确认状态分开

### Requirement: PNG下载与Prompt回读结论必须对应实际产物
声称某PNG或Prompt输出已验证时 MUST 回读真实结果：原始 PNG 记录实际文件、画面、尺寸、alpha 和哈希；Canvas PNG 另记录对应合成配置及实际画布尺寸、透明通道、画面和哈希；Prompt 记录实际剪贴板或文件文本。成功 toast、按钮可用、用户美术确认或单张抽样不能单独作为全量技术输出通过证据；有限目录声称全量通过时 MUST 明确覆盖全部适用 look、配方状态和背景。

#### Scenario: 检查一张实际下载PNG
- **WHEN** 验收者只核验一张当前模板PNG
- **THEN** 记录该文件及配置和版本，不推断其他模板下载字节或全部透明边缘均通过

#### Scenario: 检查Prompt复制
- **WHEN** 页面复制Prompt后回读系统剪贴板
- **THEN** 只在内容与当次冻结Prompt一致时记录该次通过；没有回读时保持未验证

#### Scenario: 声称当前有限输出全量通过
- **WHEN** 验收者报告当前登记模板和受支持背景输出全量通过
- **THEN** 证据逐项覆盖适用的15个 look、22个已登记配方状态和3种背景模式，回读原始 PNG 与 Canvas PNG 字节/画面/尺寸/alpha/SHA-256 以及对应 Prompt；无法执行项说明原因并保持未通过或未验证

#### Scenario: 首页视觉保持且全局随机入口可用
- **WHEN** 验收人员在固定浏览器和视口检查首页，并从现有入口打开全局随机弹窗
- **THEN** 首页布局、群像、卡片、导航和文案与冻结基线保持一致，现有随机入口可以打开和使用；未接入真实素材的随机结果仍如实标记为未验证

#### Scenario: 标签浏览不增加首页控件
- **WHEN** 用户从现有首页卡片进入图库并使用标签筛选，或在工作台打开标签浏览
- **THEN** 首页展示与文案保持不变，标签筛选只改变图库结果范围，标签控件位于图库或工作台且不会覆盖活动作品


#### Scenario: 项目菜单仅移除旧格式导出入口
- **WHEN** 验收人员在工作台打开项目菜单并执行 project v2 导出
- **THEN** 旧 `save-character` 角色 JSON 导出项不存在，v2 项目导出、菜单容器和其他菜单功能仍可用；该差异记录为旧格式停用的预期行为
