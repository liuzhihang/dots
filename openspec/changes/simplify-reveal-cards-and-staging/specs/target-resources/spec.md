# Spec Delta

## MODIFIED Requirements

### Requirement: 资源类型与动态能力必须如实区分
系统 SHALL 区分完整 Artwork 原图、静态封面、已制作动作 / 表情变体、实际动画预览和完整首页场景图。每项资源 SHALL 登记真实格式、尺寸、版本、来源及用途；预览文件和场景图不自动成为原图或下载文件。静态合成图、拼贴、CSS 位移及 Prompt MUST NOT 被标为单角色真实动画。不存在的资源能力不展示。

#### Scenario: 作品包含眨眼单帧或动作拼贴
- **WHEN** 用户查看一张眨眼 PNG 或静态 WebP 动作展板
- **THEN** 只表达单帧 / 示意能力，不提供不存在的循环播放或动画包下载

#### Scenario: 场景姿态与详情原图不同
- **WHEN** 完整首页静态场景图中的角色画法或可见状态与该 Artwork 原图不完全相同
- **THEN** 热点仍指向同一已登记 Artwork；详情和下载使用其原图，不把整景或角色裁片当成新变体、原图或动画 poster

### Requirement: 普通PNG不得标为已验证的Dot或Pet安装包
普通静态角色 SHALL 按真实登记资源提供下载。系统 MUST NOT 因透明、风格相似或附带 Prompt 而显示 Dot / Pet 安装、通用目标支持或已验证徽标。本期不展示目标资料及待验证能力占位，保留实际原图规格和操作。

#### Scenario: 下载蓝色Dots静态PNG
- **WHEN** 用户查看或下载普通完整角色图
- **THEN** 下载真实登记 PNG，页面不显示 Pet 安装、目标平台验证或未来目标包占位

### Requirement: 本期不得制作或开放未经授权的目标包
本期 SHALL 只提供已登记完整 Artwork 原图及真实存在且登记的动作 / 变体资源。系统 MUST NOT 制作、展示或开放 Pet sprite sheet、目标安装包、包导出或安装入口，不展示未证实的目标格式、许可和尺寸。后续开放目标资源须另有明确范围、实际文件及端 / 版本验证证据，不能用未来任务或占位 URL 当现有资源。

#### Scenario: 首期目录没有目标包
- **WHEN** 用户查看作品详情
- **THEN** 可下载登记的完整 Artwork 原图；Pet 包导出、安装按钮和目标平台资料入口均不存在

## ADDED Requirements

### Requirement: 页面场景与原图下载必须保持资源边界
桌面、平板与手机完整静态场景图 SHALL 按各自构图作为页面资源登记，承载场景环境、角色、台阶、道具、接触阴影和遮挡，不叠加透明角色群组。场景图 MUST NOT 被当作 Artwork 原图、下载文件或单角色动画；下载 MUST 返回当前 Artwork 登记的原始文件字节，保留真实 alpha、尺寸与 hash，不经过 Canvas 重绘。场景资源缺失或校验失败 SHALL 提供失败与重试，不替换成另一文件。

#### Scenario: 从带底色的详情下载
- **WHEN** 用户从浅色详情或首页进入后下载透明角色
- **THEN** 下载字节与登记原图一致，含真实透明 alpha，无页面底色、棋盘格、家具或新增脚底阴影

#### Scenario: 完整场景图含环境和角色
- **WHEN** 首页显示桌面、平板或手机完整静态场景图
- **THEN** 图像按页面场景用途单独登记，角色热区只指向图中现有 Artwork；下载仍使用 Artwork 原图，场景图不算新成品或批准的原图

## REMOVED Requirements

### Requirement: 目标格式资料必须记录来源端版本与验证状态
**Reason**: 本期不公开目标平台格式或安装能力资料。
**Migration**: 原来源、端 / 版本及历史验证记录保留为历史；不要求为当前静态图库增加目标平台测试或资料页面。

### Requirement: 页面底色作品背景与目标alpha必须分开
**Reason**: 原 requirement 含默认抽取 / 随机导出合同，随机产品已经取消。
**Migration**: 原图 alpha 与 UI 分离由新增“页面场景与原图下载必须保持资源边界”承接；历史静态资源验证不改写。
