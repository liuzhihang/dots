# Spec Delta

## MODIFIED Requirements

### Requirement: 详情变体必须原子切换已发布作品版本
详情 SHALL 仅显示明确同身份关系下实际存在、已发布且批准覆盖的动作 / 表情变体。切换成功时同时更新图像、名称、事实、Prompt、下载与详情地址；加载失败 SHALL 保持上一个成功版本并说明原因。无实际变体 SHALL 隐藏区块；相似系列作品不是自动变体。切换成功后修改 Prompt 草稿 SHALL 以新版本重新初始化。

#### Scenario: 切换真实动作变体
- **WHEN** 用户选择已登记且具备批准的动作版本，并成功加载校验
- **THEN** 图、事实、Prompt、下载与 URL 同时切到该版本，修改区回到默认保留；来源查询不变

#### Scenario: 没有变体或变体加载失败
- **WHEN** 当前作品没有合格变体，或所选变体加载失败
- **THEN** 前者隐藏动作 / 变体区，不显示“暂无”占位；后者继续显示上个成功版本及其所有操作，并允许重试，不把新名称配旧图

### Requirement: 详情信息层级必须优先作品与直接操作
详情 SHALL 按原图、名称、短描述、少量标签、复制 / 下载、Open in ChatGPT、Prompt 预览、真实动作 / 变体、默认折叠“创作我的版本”组织内容。英文和简体中文均可读，Prompt 全文及语言操作可达。未知或不存在的格式、许可、尺寸、Pet 安装及内部校验说明 MUST NOT 作为作品能力展示。

#### Scenario: 首次打开和重开详情
- **WHEN** 用户首次打开或重新打开详情
- **THEN** 初始焦点在顶部稳定标题，原图完整 contain，复制 / 下载先于完整 Prompt；修改区默认折叠，窄屏操作不会遮住正文

#### Scenario: 缺少许可或目标能力证据
- **WHEN** 清单未登记适用许可、实际格式、尺寸或目标安装能力
- **THEN** 详情不编造相应徽标、文字或下载选项；只显示核实的作品信息和现有资源

#### Scenario: 查看原始 Prompt
- **WHEN** 用户展开 Prompt 预览并复制原作品 Prompt
- **THEN** 复制内容与预览所选语言全文一致，不受修改区的未来创作意图污染

## ADDED Requirements

### Requirement: 首页与画廊详情必须直接提供真实作品及操作
作品详情 SHALL 展示完整原图、名称、短描述、少量事实标签、原始 Prompt、真实原图下载及 Open in ChatGPT。首页和画廊 SHALL 引用相同的 Artwork / Asset / Prompt 版本；下载与复制冻结所发起操作的版本。详情立即响应打开，加载与失败状态可见；MUST NOT 要求先进入工作台、完成动画或修改图片。

#### Scenario: 从首页和画廊打开详情
- **WHEN** 用户点击某个角色或作品卡片
- **THEN** 同一详情立即出现，资料与资源版本一致，可在原图加载期间关闭或返回；不等待角色动画结束

#### Scenario: 原图加载失败
- **WHEN** 原图读取、校验或解码失败
- **THEN** 原图区域显示失败与重试当前资源，下载不可伪报成功；已验证的文字 Prompt 可独立复制，不静默替换作品

#### Scenario: 下载期间切换作品
- **WHEN** 用户对 A 发起原图下载后切换到 B
- **THEN** 若下载完成则输出 A 的真实文件；取消则如实提示，不混入 B 的图像、名称或 Prompt，迟到回调不覆盖 B 的状态

## REMOVED Requirements

### Requirement: 作品详情必须直接提供实际图片及带走操作
**Reason**: 此要求包含已取消的随机、游戏或独立参考图会话场景，整体由新静态体验合同替代。
**Migration**: 采用“首页与画廊详情必须直接提供真实作品及操作”及其场景；保留真实操作、无障碍和恢复能力，旧运行合同不继续生效，历史证据不改写。
