# Dot Icon Studio 产品与设计约定

Dot Icon Studio 以完整角色作品为核心：用户通过首页专题、画廊搜索或随机卡片发现成品，查看并复制对应 Prompt、下载原图，或带着参考图要求在 ChatGPT 继续创作。用户可以在外部对话中创作；完成作品后的上传、存储和审核是后续独立产品方向，揭晓卡改动不包含这套流程。

## 视觉与身份

总体页面沿用用户选定的 Dot Icon Studio 展板：品牌、中央主标题、左右群像、明亮氛围、专题卡、画廊与大图详情。抽卡参考用户喜欢的“随机生成一个可爱角色”弹窗，以及总览图下方的逐卡与结果展示。工作台参考图中的滑杆编辑器不是本产品的页面方向。参考图只指导视觉层级，不能作为可交互页面或批准角色素材。

首批身份保留 Dots、Grok Bot、Meta Muse、原创人物和动物；五类专题是内容入口，不构成永久数量限制。Dots 新制美术保持柔软短绒；Grok Bot 保持软几何与成对胶囊眼；Meta Muse 保持奶油包覆外形和内嵌脸面。人物、动物保持清楚的原创身份与真实结构。已批准原图不因新原型或新风格要求而静默修改或扩大批准范围。

## 内容与操作

Artwork 记录图中真实事实、资源、Prompt、来源和批准状态。配件素材可以独立制作，并在适用时由多个作品显式复用，作为抽卡线索展示；它不负责贴合角色或把配件装到角色上。每个最终停止值都必须对应所揭晓成品中的真实内容。

底层事实保留角色风格、外形、五官、配色材质、衣物、头部配饰、身体饰品和随身道具。角色风格不再单独占卡；Dots、Grok Bot、Muse、人物、动物身份标签在第一张外形五官卡停稳时轻量出现。揭晓卡按外形五官、配色材质、衣物、配饰、道具排序，前两类必显，后三类只在作品含有真实且已核实的内容时显示。同类多项配件共用一张卡；已核实无值时省略卡片但保留事实，未知事实不能被当作无值，也不能靠隐藏卡片绕过。卡数随真实有值类别变化，同轮在动画开始前固定；当前 15 件作品为 2 张卡 7 件、3 张卡 7 件、4 张卡 1 件。不为统一卡数补空卡，也不截断未来真实存在的类别。

首张外形五官卡只揭示作品的真实局部线索；它停稳时才显示轻量身份标签，不泄露最终图、专属配色、服饰、配饰、作品名或简介。滚动卡与停卡只展示素材图和简短类别名；特征短名和说明在卡片上都不出现。紧凑深色舞台在桌面一排呈现本轮 2–5 张卡，角色在结果阶段成为视觉主体；手机突出当前卡并露出邻卡。所有卡停稳后保留约 900ms 隐藏结果，再于同一舞台收拢线索卡并揭晓完整角色与作品名。主按钮“带走伙伴”打开内联操作面板，提供复制 Prompt、下载图片、ChatGPT 和 Feature 锁定；“再遇一位”为次级操作，详情入口保持轻量。完整描述仅在详情中出现。减少动态模式展示同一套静态卡并等待“揭晓伙伴”。图片在揭晓前及替代文本中也不得泄露最终角色。

首页与游戏使用默认有效池，画廊随机继承当前查询。三个入口复用抽取模型和 DrawResult。抽取前与动画中不展示锁定控件；揭晓后可锁定实际 Feature 供下一次抽取，多个必备条件按 AND 求交。资源加载失败时提供恢复操作，不偷偷替换角色或素材。角色原图保持登记像素颜色，下载原字节。

参考图入口当前只提供风格、描述、保留项与条件式文字 Prompt；用户在 ChatGPT 自行附图并发送。本站不声称已分析或上传图片。完整事实可用于搜索，详情显示精选标签与真实资源规格，复制 Prompt 和下载原图为主操作。

## 输出与批准

完整角色、线索素材、页面候选、来源资格、工程校验、用户艺术批准、目标验证及发布状态分别记录。共享线索素材的每个作品关联必须符合真实特征；一份素材被复用不扩大它的批准范围。候选预览保持 pending，不改变现有 Artwork 批准。

普通 PNG 不表示 Dot/Pet 安装能力；没有真实目标验证不提供安装或目标包下载。页面底色属于 UI，不进入透明原图。视觉检查覆盖桌面和 320/390/768 CSS px 模拟视口；实体设备、用户美术批准和站点发布分别确认。
