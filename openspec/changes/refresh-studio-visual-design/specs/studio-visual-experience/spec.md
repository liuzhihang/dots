# Spec Delta

## Purpose

定义 Dot Icon Studio 按已确认的 R01 设计方向呈现首页与创作工作台的页面体验，使五个角色家族、当前创作入口和所选角色形成清楚连贯的视觉层级。

## ADDED Requirements

### Requirement: 已发布页面必须加载同一版本的角色素材目录
系统 SHALL 为入口及其可达本地 ES module 依赖采用同一发布版本 URL，使已缓存旧子模块的访问者也能读取新的五家族目录。Meta Muse SHALL 在导航、家族卡片、主视觉及 Artwork 工作台使用自身基准。用户明确否决的卷发阅读人物 MUST NOT 继续作为可选作品或公开图片发布。

#### Scenario: 手机访问者曾缓存旧角色目录
- **WHEN** 访问者加载新版首页入口
- **THEN** 全部本地模块依赖指向新版 URL，并显示五组各自的基准，包括 Meta Muse，而不是复用只有四张历史图的旧目录

#### Scenario: 导入已撤下人物作品的项目
- **WHEN** 导入保存了被否决卷发阅读人物 ID 的项目
- **THEN** 人物配置及作品 ID 保留，页面明确显示原图已撤下并禁用图片导出，不静默替换为新基准或恢复已撤下文件

### Requirement: 首页与创作工作台必须遵循 R01 的视觉层级
系统 SHALL 以已确认的 R01 为首页和创作工作台的视觉依据，使用简洁品牌栏、鲜明主标题与创作入口、轻盈明亮的家族展示区，以及明确聚焦当前角色的编辑与预览区域。首页主视觉 SHALL 由五个家族各自的独立角色素材组成，而不是整张设计图或页面效果图；每个素材 SHALL 与其家族身份一致。主次层级、字体、留白、色板、圆角、卡片和控件 SHALL 保持一致；实现 MUST NOT 将参考站点的视觉主题直接移植进来。

#### Scenario: 初次打开首页
- **WHEN** 用户在桌面或移动端打开 Dot Icon Studio
- **THEN** 首页清楚呈现产品用途、开始创作入口与五个独立家族；用户进入工作台后可见当前角色、创作模式和主要操作，不以旧式密集编辑表单遮蔽主要任务

#### Scenario: 首页显示五家族独立角色素材
- **WHEN** 用户查看 R01 首页主视觉
- **THEN** 五个家族分别由各自独立的角色素材表现，素材不是整张拼接网页截图或模拟产品界面，且不会把任何素材状态标作已通过美术验收

#### Scenario: 进入创作工作台
- **WHEN** 用户从首页进入或滚动至当前角色的创作区域
- **THEN** 角色预览、该组身份、主要可编辑项和下一步创作操作有清楚的视觉层级，并延续首页的品牌、色彩与组件规则

### Requirement: 页面必须保留五个独立家族的视觉身份
家族展示区 SHALL 将 Dots、Grok Bot、Meta Muse、人物、动物作为五个独立家族呈现，分别使用清晰名称、独立说明和一致的卡片层级。每组在本轮 SHALL 只展示一只基准候选；历史素材、概念稿和不完整组合能力 MUST 以真实状态呈现，不能暗示为已通过美术验收或可用的生成结果。家族切换行为遵循独立的分类导航 change。

#### Scenario: 查看五个家族
- **WHEN** 用户浏览首页的家族展示区
- **THEN** 五个名称与其角色展示一一对应，Meta Muse 不与人物合并，动物不与人物合并，也没有第六个家族或批量候选

#### Scenario: 浏览尚未完成美术验收的基准
- **WHEN** 家族基准尚未通过真实页面美术验收和该组用户确认
- **THEN** 页面只呈现当前一只候选并如实表达其候选/未确认状态，不以概念图、旧图、构建或逻辑检查标注为已验收

### Requirement: 首页与创作区必须适配常用视口且保持可读可用
系统 SHALL 使首页、五家族展示区和创作工作台适配桌面、平板及 320 px、390 px、768 px 宽度。窄视口中内容 SHALL 按自然阅读顺序重排；标题、角色主体、必要状态说明和主要创作操作 MUST 保持可见且不被横向溢出遮挡。

#### Scenario: 以窄手机浏览
- **WHEN** 页面视口为 320 px 或 390 px
- **THEN** 品牌、主标题、家族入口、角色预览和主要创作操作仍可辨识与触达，页面不出现导致内容无法访问的水平溢出

#### Scenario: 以平板浏览
- **WHEN** 页面视口宽度为 768 px
- **THEN** 家族与编辑区域采用适合触控的布局，内容顺序和状态说明仍清晰，预览不会被控制区挤压到不可辨识

### Requirement: 页面不得加入登录和个人空间产品路径
系统 MUST 允许用户直接浏览家族、编辑当前角色并使用本站已支持的带走方式，而无需注册或登录。页面 MUST NOT 提供登录、账号、我的空间、云端作品库或收藏个人角色的产品流程。

#### Scenario: 直接开始创作
- **WHEN** 新用户打开站点并开始选择或编辑角色
- **THEN** 用户无需建立账号或进入个人空间即可继续创建流程

#### Scenario: 检查页面主导航
- **WHEN** 用户查看桌面或移动页面导航
- **THEN** 导航只呈现当前站点真实可用的内容与创作入口，不显示登录、我的空间或云端保存入口
