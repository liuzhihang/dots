## 问题与修复

用户截图中的配饰均有登记素材。Figure 缩略图加载器却关闭了 WebP delivery，直接请求只保留在源码目录的 PNG。正式发布目录按清单排除这些 PNG，导致线上红叉；从完整本地 `dist/` 启动则会掩盖问题。

本次只将 Figure 缩略图恢复到既有登记的无损 WebP 传输，并强制 delivery coverage。相对于107，除缓存查询与版本号更新外，唯一运行逻辑变化位于 `dist/studio-figure-editor.js`；CSS、素材、批准记录和配方保持不变。

- 灰色“无配饰”叉是空值图标。
- 红叉表示缩略图加载失败，本次修复其错误传输路径。
- 预览正在更新时，选项会暂时禁用；不兼容组合会持续禁用。蓝色圆球闭眼时黑色墨镜与赛博眼镜没有对应配方，切回睁眼后可选。图片可见与组合可用性是不同状态。
