## 用户问题与最终变化

旧版缩略图只有56px，黑色眼镜难以从深色背景中分辨。先前的独立灰色底块虽增加对比，但与网站风格不协调。

最终方案将真实素材展示区域放大至76px，使用与网站focus/accent-light一致的淡紫柔光覆盖卡片上半部，并向下渐隐到深色底。缩略图区域本身透明，去除内层底框、减轻阴影；空配饰、加载中和已加载选项保持同一层级。选中边框和内阴影继续标记当前选择。

图片等待时显示轻量加载环与aria-busy；ready/error后停止，减少动态效果时保留静态环。配方兼容性不改变，界面配色不进入素材或PNG导出。
