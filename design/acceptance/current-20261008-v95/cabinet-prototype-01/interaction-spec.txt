Dot Icon Studio · 玩偶展示柜原型交互说明
版本：2026-10-08 / 视觉概念，待用户审阅
范围：桌面首页、桌面角色详情、移动首页的静态原型，以及拟议交互。没有修改运行站点；本文件不代表功能或目标平台已验证。

页面结构
- 首页为角色展柜本身，不再叠加大型群像封面、单角色轮播或抽卡。
- 品牌与短标题之后，直接进入系列筛选、搜索、角色展格。
- 桌面参考四列；移动参考两列。实际实现还需在 320/390/768 CSS px 与桌面检查字号、目标尺寸与换行；原型像素尺寸不等同 CSS 视口。
- 保留 Dots、Grok Bot、Muse、人物、动物系列，Dots 占主要展示位置。“精选”允许混合系列；选择 Dots 后只出现 Dots，不混入其他家族。
- 展柜为浅景深网页陈列，不是可拖拽旋转的真实 3D 房间。图像只展示已制作姿态，不假装有未制作动画。

浏览与查找
- 默认“精选”，选择一个系列后更新展柜。关键字与系列筛选同时生效。
- 匹配角色名称与已登记标签。清空关键字保留所选系列；“重置筛选”恢复精选。
- 无结果时显示“没有找到这个伙伴”，提供清空条件入口。
- “查看更多形象”追加展示，不自动切换现有玩偶或把用户带回顶部。
- 桌面移入或键盘聚焦整格：灯光轻微提亮、紫色细描边、出现“查看伙伴”。名称始终可见。
- 轻微动效约 150–200ms；减少动态时保留静态焦点描边即可。不要求所有角色自动晃动、眨眼或播放。
- 整格具有明确可访问名称；键盘 Enter 与鼠标点击同效。手机整格直接点选，不依赖 hover。

详情与返回
- 点击角色进入该作品的详情，绑定同一作品图、Prompt 和资源，不能因切换示例而错配。
- 桌面左侧大图，右侧名称与创作操作；移动详情应按大图、名称、操作纵向呈现，后续单独检查。
- 返回展柜恢复原系列、关键词和滚动位置。分享作品使用其稳定详情链接。
- 原型以蓝帽云朵示例展示；原图可放大查看。未登记其它角度/动作时不显示假缩略图、360 度拖转或播放控件。

两条创作路径
1. 已有自己的图片：
   首页“用自己的图片创作”进入创作指南，选 Dots/Grok Bot/Muse 等系列，获取系列风格 Prompt；用户在 ChatGPT 附上自己的图片。
2. 喜欢当前作品：
   详情“复制角色 Prompt”复制当前作品对应的提示词；
   “下载参考图”保存当前作品原图；
   “在 ChatGPT 中创作”打开外部 ChatGPT，并清楚提示自行附图与发送。
   不把打开网页当作图片已上传，不把复制按钮当作生成完成。
- 系列风格 Prompt 与作品专属 Prompt 分开命名，不能用一个含糊按钮覆盖两个不同用途。
- 复制成功反馈“已复制”；失败提供选中文本手动复制，不显示假成功。

下载与使用
- 普通原图按原字节下载，保留真实 alpha；网页展柜、底色、灯光不会烘焙到下载图片。
- Pet 文件存在且完成对应目标验证后，才显示“下载 Pet”或真实安装入口。
- 本次详情原型只提供制作成 Pet 的指南入口，不伪造现成 Pet 安装包。
- 用户在外部 ChatGPT 创作；站内生成、账号、投稿上传、审核、数据库管理均不在这次原型内。

视觉与资源边界
- Dots 采用短绒；Grok Bot 明确采用光滑软几何与胶囊眼；Muse 保持奶油包覆与内嵌脸。
- 角色是主角，柜框、灯光、铭牌克制，不添加玻璃门、过度反射、价格或购物车。
- 原型里的角色必须后续独立制作为合格资源，不能从整页原型截图裁出像素作为正式素材。
- 图像原型只用于讨论设计，不证明交互已经可用、移动端已适配、素材获用户艺术批准或 Pet 能安装。
