Use case: ui-mockup
Asset type: 精品品牌网站首页桌面概念图
Primary request: 为 Dot Icon Studio 设计「伙伴街区」首页概念。把角色放进可逛的微缩玩具街区，让用户通过清晰、轻松的点击探索角色，并进入角色详情获取创作参考。
Input images: Image 1 是现有 Dot Icon Studio 展柜首页，仅用于保留品牌、暖白与紫色点缀、角色身份和短绒/光滑材质差异；Image 2 是用户提供的角色生活群像，仅用于参考角色在连贯场景中的生活感与分散构图，不复制其具体画法、人物或河桥。
Scene/backdrop: 一个连续、连通的微缩玩具街区，低角度等距娃娃屋近景；三个相连的区域：音乐角、创作小屋、花园。街道与地面自然连接，场景是网站首页的主要内容。
Subject: 8–10 个大而清楚的角色在各自区域自然生活。音乐角有粉色耳机球与紫色云；创作小屋有蓝色贝雷帽云与光滑白色 Grok Bot；花园有奶油包覆、内嵌脸面的 Muse 与绿色方块；附近出现戴圆眼镜的黄色三角、男孩和柴犬。可配小乐器、画架、花盆，但不遮挡角色脸或轮廓，角色不得被建筑挡住。
Style/medium: 高品质 3D 微缩玩具场景，精品玩偶品牌的真实网页 UI；柔和、亲切、精致。Dots 短绒，Grok Bot 是光滑柔软的几何形，保留成对胶囊眼，不画屏幕脸；Muse 使用奶油包覆形体和内嵌脸面。明亮自然柔光，细腻材质，角色大小适合辨认和点击。
Composition/framing: 1440×1024 桌面浏览器内容截图，无浏览器/设备框，无拼图。场景占页面主体约 65–75%，是单一连续街区，不是卡片网格、不是游戏地图、不是河桥。顶部保留轻盈网站导航，内容区先放标题与区域筛选，主体大幅呈现街区；让人物明显大于建筑细节。场景选择的「蓝帽云朵」在左中区域带有柔和紫色轮廓，并有轻盈浮动气泡「蓝帽云朵 · 查看伙伴 →」。右上角显示「场景 | 图集」，「场景」选中。底部以一道浅分隔显示简洁说明「选参考形象 → 在 ChatGPT 创作 → 保存你的版本」。不要加入说明长文。
Lighting/mood: 温暖、明亮、安静有趣，像一条值得慢慢逛的玩具街；层次清楚，用户首先看见角色而不是复杂布景。
Color palette: 暖白网页底色，黑色文字，紫色作为少量品牌交互强调色；街区用奶油黄、淡绿、浅蓝、粉色。
Materials/textures: 短绒、柔软几何塑料、奶油针织、木质小道、哑光房屋，材质差异要可信且易辨。
Text (verbatim): 顶栏「Dot Icon Studio」「首页」「头像库」「创作指南」；标题「欢迎来到，伙伴街区。」；副标题「逛一逛，带走你的创作灵感。」；筛选「全部」「音乐角」「创作小屋」「花园」；视图切换「场景」「图集」；选中浮层「蓝帽云朵 · 查看伙伴 →」；底部「选参考形象 → 在 ChatGPT 创作 → 保存你的版本」。
Constraints: 让街景连续可逛，三个区域容易读懂；角色全身与表情清楚、尺寸够大；每位角色都是可点击的真实作品入口，选中角色视觉上突出。页面看起来像可用的网站首页，不像纯插画海报。无价格、购物车、任务计数、关卡、收藏进度、抽卡动画。中文尽量准确清晰，所有文字克制且可读。
Avoid: 河流、拱桥、棋盘/象棋、战斗、密集群像、角色重复、角色过小、人物被建筑遮挡、卡片网格、地图UI、复杂按钮堆叠、机器人屏幕脸、全部角色同一种毛绒质感、宣传海报、设备框、浏览器框、水印。
