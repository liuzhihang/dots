| 范围 | 采用 | 不作为本轮能力依据 |
|---|---|---|
| Dots | 短密绒；球形之外也可有云状、三角、心形等独立成品轮廓；成对眼睛；帽/眼镜/耳机等需真实接触；全部无手脚 | 不从带手脚的旧营销图生成四肢，不把长毛玩偶材质当默认，不把设置截图里的所有 Shape/Extras 直接开放给当前固定球体模板 |
| Grok Bot | 软几何、光滑/柔软体块、多种独立轮廓、成对胶囊眼；全部无手脚 | 不混成屏幕脸机器人，不添加毛绒、手脚，不因同系列就继承球体模板 |
| 首页 | D01 深色数字画布仍是唯一页面主稿；真实角色本体完整呈现 | 不改回白色设置应用，不复用截图 UI/文字/账号名，不增加 Pets 入口 |
| 编辑 | 色块和真实素材缩略图、清楚的选中状态 | 本轮仍只开放已适配的2套Template；图中其他形状和配件需要未来独立素材/适配，不是假选项 |
