# 首页 Hero 制作来源

本目录保存最终首页群像的原始生成图、初始 Prompt、耳机领带兔子的修订 Prompt 与来源 manifest。`hero-ensemble-source.png` 的 SHA-256 与 manifest 中的 `sourceSha256` 一致。

`manifest.json` 保留制作当时的 pending 状态原文；当前用户批准与发布状态以 [2026-10-11 精确批准记录](../../../release-20261011/approval.json) 和 [部署回执](../../../release-20261011/deployment.json) 为准。运行素材是 `dist/assets/banners/dots-gallery-hero-ensemble-v99.webp`，该插画只作 UI 装饰，不是可导出的 Artwork。
