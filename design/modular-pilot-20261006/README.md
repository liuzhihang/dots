# 独立组件试点

本批次有 3 个基础设计、0 个活动配色/材质变体、4 个声明的组件×基底适配，登记 5 条组合配方。新组件的美术批准数当前为 0；声明范围不等于工程或美术通过。24 款基础设计是后续分批目标，杯子和抓握尚未制作。

| 组件 | 基底和完整姿态 | 类别 | 当前资格 |
| --- | --- | --- | --- |
| 石墨紫绒耳机 kit 2.0.0 | Dots 裸形 / bare-classic；栗发人物 / classic | 耳机 | 动态拟合试用，逐适配待美术确认 |
| 棕色圆框眼镜 1.0.0 | 栗发人物 / classic | 眼镜 | 工程试用，待本适配美术确认 |
| 青绿针织围巾 1.0.0 | 柴犬 / classic | 颈饰 | 工程试用，待本适配美术确认 |

组件由内置 ImageGen 独立制作，未从完整模板或参考截图裁切。来源、文件尺寸、透明通道、SHA-256、几何 profile、fitPolicy 和源部件见 [assets.json](assets.json)，生成及修订说明见 [prompts.json](prompts.json)。耳机当前活动文件为独立生成的 v4 kit：连续头梁、左耳罩、右耳罩在同一透明 atlas 中分别登记，不算三个设计。v1–v3 仅保留为工程草稿；蓝白 v2 的展示组合被用户否决，见[反馈记录](user-coordination-feedback.json)。

围巾当前原稿存在外部光晕；两次 ImageGen 修订仍未达到透明边缘要求，未注册为新素材或宣称修复。它保持试用、待美术确认并排除默认随机，实际合成图的材质光照项须记录问题。

基底沿用现有完整 PNG，保持其像素和身体结构。当前视角为正面、姿态为静态；穿搭、手部和其他完整模板内容不能从基底中拆出或随意移除。动态适配依据绑定真实基底版本的维护者几何标注：耳机按头顶与耳侧接触点分别解算头梁、耳罩；眼镜按两眼锚点解算比例与朝向；围巾按颈部接触点解算。人物另登记耳机＋眼镜共存配方，共用同一几何 profile，逐组件解算并统一检查槽位与层序。不声称组件通用、任意姿态或连续动画。

维护者在 `dist/studio-composition-catalog.js` 登记素材合同及完整配方；工作台、恢复、随机候选、内部图鉴、Canvas 和 PNG 导出使用同一 resolver。素材版本/hash、几何 profile、锚点、源部件、策略或配方改变后，原适配批准不会自动覆盖新版本。组合与各组件分别保存 fit 指纹，PNG 捕获记录实际变换与层序。比例、接触、遮挡、材质光照、配色五项协调性检查独立于用户美术批准。未经批准的适配可以明确试用和保存，但不进入默认随机或精选推荐。

后续分类按实际内容扩充：帽子、发饰、耳机、眼镜、内搭、外套、下装、连体服装、颈饰、腕饰、鞋、包袋、手持/使用道具、牌面及动物专属穿戴。牌面内容、挂载与文字分开；没有对应身体结构和姿态/抓握配方的基底不适配鞋、腕饰或手持道具，不自动增加肢体。

真实输出、浏览器和响应式证据另绑定最终源码版本冻结在 `design/acceptance/`。生成图与此设计清单本身不构成网页美术验收。
